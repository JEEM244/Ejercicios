# Templates

Use these templates as starting points. Remove bracketed instructions when creating a real document and keep only sections that add value.

| Template | Purpose |
|---|---|
| [TEMA.en.md](TEMA.en.md) | Explain a concept or tool |
| [EJERCICIO.en.md](EJERCICIO.en.md) | Define practice with requirements and tests |
| [SOLUCION.en.md](SOLUCION.en.md) | Document a separate solution |
| [RETO.en.md](RETO.en.md) | Define a broader challenge |
| [PROYECTO.en.md](PROYECTO.en.md) | Plan an integrated project |

English templates use the `.en` suffix. Source files do not need to be duplicated when code is identical; translate the documentation.
