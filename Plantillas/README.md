# Plantillas

Usa estas plantillas como punto de partida. Elimina las instrucciones entre corchetes al crear un documento real y conserva solo las secciones que aporten valor.

| Plantilla | Uso |
|---|---|
| [TEMA.md](TEMA.md) | Explicar un concepto o herramienta |
| [EJERCICIO.md](EJERCICIO.md) | Definir una práctica con requisitos y pruebas |
| [SOLUCION.md](SOLUCION.md) | Documentar una solución separada |
| [RETO.md](RETO.md) | Proponer un desafío de mayor alcance |
| [PROYECTO.md](PROYECTO.md) | Planear un proyecto integrador |

Las plantillas en inglés usan el sufijo `.en`. No es necesario duplicar archivos de código cuando el código es idéntico; traduce la documentación.
