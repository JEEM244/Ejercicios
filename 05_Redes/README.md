# Redes

Fundamentos de comunicación entre equipos, aplicaciones y servicios.

## Contenido previsto

- Conceptos y modelos de red.
- Direcciones IP, subredes y puertos.
- TCP y UDP.
- DNS.
- HTTP y HTTPS.
- Solicitudes, respuestas y códigos de estado.
- Cliente, servidor y arquitectura.
- Herramientas de diagnóstico en entornos autorizados.

## Uso responsable

Las prácticas se limitarán a redes, equipos y servicios propios o con autorización. Se priorizará comprender protocolos, diagnosticar conectividad y analizar tráfico de laboratorio.
