# Proyectos

Proyectos pequeños e integradores para aplicar varias habilidades en un resultado funcional.

## Niveles

- **Principiante:** programas pequeños, calculadoras, conversores y utilidades.
- **Intermedio:** aplicaciones modulares, persistencia local, formularios y APIs.
- **Avanzado:** integración, arquitectura, rendimiento, pruebas y decisiones técnicas.

## Requisitos de cada proyecto

Debe tener propósito, alcance, requisitos verificables, estructura inicial, plan de trabajo, criterios de aceptación y notas de decisiones técnicas.

**Estado:** estructura inicial; catálogo de proyectos pendiente.
