# Projects

Small, integrated projects for applying multiple skills to a working result.

## Levels

- **Beginner:** small programs, calculators, converters, and utilities.
- **Intermediate:** modular applications, local persistence, forms, and APIs.
- **Advanced:** integration, architecture, performance, testing, and technical decisions.

## Project requirements

Every project needs a purpose, scope, verifiable requirements, initial structure, work plan, acceptance criteria, and technical decision notes.
