# Progreso

El seguimiento es local y opcional. No bloquea el acceso al material ni exige completar una ruta.

## Archivo principal

`progreso.json` guarda el estado general por lenguaje y área. Puedes editarlo con cualquier editor de texto.

## Estados sugeridos

- `not_started`: todavía no iniciado.
- `in_progress`: en estudio.
- `review`: necesita repaso.
- `completed`: revisado y practicado.

Leer una explicación no basta para marcar un tema como completado. Conviene probar un ejemplo o resolver una práctica.

## Notas

Registra dudas, errores que quieras recordar y ejercicios que convenga repetir. No guardes contraseñas ni datos sensibles.
