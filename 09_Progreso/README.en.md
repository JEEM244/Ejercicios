# Progress

Tracking is local and optional. It does not block access to material or require a fixed learning path.

## Main file

`progreso.json` stores the general status of each language and area. Edit it with any text editor.

## Suggested statuses

- `not_started`: not started yet.
- `in_progress`: currently studying.
- `review`: needs review.
- `completed`: reviewed and practiced.

Reading an explanation alone is not enough to mark a topic complete. Try an example or solve a practice task first.

## Notes

Record questions, mistakes worth remembering, and exercises to repeat. Do not store passwords or sensitive data.
