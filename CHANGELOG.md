# Registro de cambios

Los cambios importantes de CodeVault se registran aquí.

## 0.9.0 - 2026-11-24

### Agregado
- Primera ruta de fundamentos de JavaScript con guía y referencia rápida bilingües.
- Ejemplos de ejecución en navegador y Node.js, variables, tipos, conversiones, operadores, condicionales, ciclos y funciones.
- Seis ejercicios JS-001 a JS-006 con enunciados bilingües y archivos iniciales.
- Soluciones separadas con archivos de código y explicaciones en español e inglés.

### Actualizado
- Índice de JavaScript y plan de desarrollo.
- Revisión estática de CSS-012: seis páginas revisadas entre inicio y solución; sin rutas locales faltantes, enlaces internos rotos ni IDs duplicados. Las pruebas de navegador siguen pendientes.

## 0.8.0 - 2026-11-24

### Agregado
- Proyecto integrador CSS-012: sitio de aprendizaje con páginas de inicio, temas y contacto.
- Estructura HTML inicial y solución completa con una hoja CSS compartida.
- Práctica de Grid, Flexbox, variables, breakpoints, foco de teclado y movimiento reducido.
- Documentación bilingüe, criterios de aceptación y pruebas manuales.

### Actualizado
- Índice de ejercicios CSS: ahora incluye doce prácticas y un proyecto integrador.
- README de CSS y estado de la ruta.

## 0.7.0 - 2026-11-24

### Agregado
- Ampliación de CSS con flujo normal, desbordamiento y posicionamiento.
- Guía de Flexbox y CSS Grid, con criterios para elegir entre ambos modelos.
- Diseño adaptable con media queries y una introducción a container queries.
- Variables personalizadas, transiciones, transformaciones, animaciones y movimiento reducido.
- Ejercicios CSS-006 a CSS-011 con versiones bilingües, archivos iniciales y soluciones separadas.

### Actualizado
- Guías y referencias de CSS.
- Índice de ejercicios CSS: ahora incluye once prácticas.
- README de CSS y estado del plan de desarrollo.

## 0.6.0 - 2026-11-24

### Agregado
- Primera unidad de CSS con guía y referencia rápida en español e inglés.
- Explicaciones de sintaxis, selectores, combinadores, pseudoclases y pseudoelementos.
- Temas de cascada, especificidad, herencia, modelo de caja, unidades, colores y tipografía.
- Cinco ejercicios CSS-001 a CSS-005 con archivos iniciales, soluciones y explicaciones bilingües.

## 0.5.0 - 2026-11-24

### Agregado
- Proyecto integrador HTML-010 con páginas principal, contacto y recursos.
- Archivos iniciales y solución de referencia para el proyecto.
- Recursos SVG originales, estilos mínimos y script externo.
- Criterios de aceptación y autoevaluación para revisar la práctica.

### Actualizado
- Índice de ejercicios HTML: ahora incluye diez prácticas.
- README de HTML: ruta inicial básico-intermedio completada.
- Se corrigieron los recursos CSS y JavaScript de inicio para HTML-007.

## 0.4.0 - 2026-11-24

### Agregado
- Ampliación de HTML con metadatos, atributos globales y carga de recursos externos.
- Explicación de defer, async y módulos JavaScript.
- Imágenes adaptables, picture, srcset y sizes.
- Contenido incrustado con iframe y uso restrictivo de sandbox.
- Elementos interactivos nativos: details, summary y dialog.
- Elementos de estado progress y meter.
- Ejercicios HTML-007, HTML-008 y HTML-009 con versiones bilingües.

## 0.3.0 - 2026-11-24

### Agregado
- Ampliación de HTML con tablas, formularios, audio, video, accesibilidad y validación.
- Ejercicios HTML-004, HTML-005 y HTML-006 con archivos iniciales y soluciones separadas.
- Ejemplo de subtítulos WebVTT y transcripción de muestra.

## 0.2.0 - 2026-11-23

### Agregado
- Catálogo de fuentes de consulta para lenguajes, fundamentos, herramientas, tecnologías y redes.
- Primera unidad de HTML con guía, referencia y ejercicios iniciales.
- Convenciones para redactar material original y registrar referencias.

## 0.1.0 - 2026-11-23

### Agregado
- Inicialización del repositorio JEEM244/Ejercicios como CodeVault.
- Documentación general, especificación e índices en español e inglés.
- Alcance inicial de once lenguajes y áreas compartidas.
- README por lenguaje y por área.
- Plantillas bilingües para temas, ejercicios, soluciones, retos y proyectos.
- Registro local de progreso en JSON.
- Reglas de mantenimiento, seguridad y formato del repositorio.
