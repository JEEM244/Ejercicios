# Registro de cambios

Los cambios importantes de CodeVault se registran aquí.

## 0.3.0 - 2026-11-24

### Agregado
- Ampliación de la guía HTML con tablas, formularios, audio, video, accesibilidad y validación.
- Referencia rápida de elementos, atributos, formularios y multimedia.
- Ejercicios HTML-004, HTML-005 y HTML-006 con archivos iniciales.
- Soluciones separadas para las tres prácticas.
- Ejemplo de subtítulos WebVTT y transcripción de muestra.
- Versiones en inglés de la guía, referencia, ejercicios y explicaciones de soluciones.

### Actualizado
- Índices de ejercicios y páginas README de HTML.
- Estado de las fases de biblioteca técnica y entrenamiento: HTML en desarrollo.

## 0.2.0 - 2026-11-23

### Agregado
- Catálogo de fuentes de consulta para lenguajes, fundamentos, herramientas, tecnologías y redes.
- Primera unidad de HTML con guía, referencia y ejercicios iniciales.
- Convenciones para redactar material original y registrar referencias.

## 0.1.0 - 2026-11-23

### Agregado
- Inicialización del repositorio JEEM244/Ejercicios como CodeVault.
- Documentación general, especificación e índices en español e inglés.
- Alcance inicial de once lenguajes y áreas compartidas.
- README por lenguaje y por área.
- Plantillas bilingües para temas, ejercicios, soluciones, retos y proyectos.
- Registro local de progreso en JSON.
- Reglas de mantenimiento, seguridad y formato del repositorio.
