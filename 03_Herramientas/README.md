# Herramientas

Herramientas que acompañan el trabajo diario de desarrollo.

## Contenido previsto

- Git: repositorios, commits, ramas, merges y resolución de conflictos.
- Terminal: rutas, archivos, procesos y comandos.
- Bash: scripting y automatización en sistemas compatibles.
- PowerShell: cmdlets, objetos y scripts en Windows y otros sistemas.
- Linux: estructura del sistema y administración básica.
- Expresiones regulares: patrones y validación de texto.

## Enfoque

Cada comando explicará su propósito y sus efectos. Los ejemplos que cambian o eliminan archivos deberán indicarlo claramente.
