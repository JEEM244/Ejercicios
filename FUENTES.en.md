# Reference sources

This catalog lists the references used to prepare CodeVault guides, quick references, examples, and exercises.

Sources are used for research and cross-checking. **Complete courses, articles, exercises, and solutions will not be copied.** CodeVault content is written in original wording, with new examples and practice tasks.

## How sources are used

1. **Verify concepts and syntax:** prefer standards, official documentation, and manuals maintained by technology owners.
2. **Plan learning:** use tutorials and courses to guide topic order and prerequisites.
3. **Design exercises:** use references to identify skills to practice, but write original prompts, data, test cases, and solutions.
4. **Record provenance:** each guide and exercise set lists the sources actually consulted.
5. **Review changes:** note versions or standards when relevant and periodically check living documentation.

## Usage criteria

1. Prioritize official documentation for syntax, behavior, and compatibility.
2. Use educational repositories to inspire practice sequences, not as material to copy.
3. Verify technical details when sources disagree.
4. Write original explanations, examples, and exercises.
5. Include a version or access date when content may change.
6. Link each source next to the topic it supports.
