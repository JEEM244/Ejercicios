# CodeVault

Biblioteca personal de aprendizaje y práctica de programación. Reúne guías, referencias rápidas, ejercicios, retos y proyectos pequeños en una estructura consultable y ampliable.

**CodeVault no es un curso lineal ni una plataforma web.** Es un repositorio de estudio: puedes entrar por el tema que necesites, leer la explicación, probar el código y volver a practicar más adelante.

## Objetivos

- Aprender desde los fundamentos hasta temas avanzados.
- Mantener frescos los conceptos mediante práctica recurrente.
- Consultar sintaxis, ejemplos y errores comunes sin buscar desde cero.
- Mejorar lógica, lectura de código, depuración y diseño de soluciones.
- Comparar cómo resuelven un mismo problema distintos lenguajes.
- Construir proyectos pequeños que conecten los temas.

## Cómo usarlo

1. Elige un lenguaje, concepto o problema desde el [índice](INDICE.md).
2. Lee la guía o la referencia correspondiente.
3. Abre el ejercicio y revisa sus requisitos y casos de prueba.
4. Resuelve primero sin consultar la solución.
5. Compara tu resultado y registra lo que quieras repasar.

No es obligatorio seguir un orden. Los prerrequisitos se indican en cada tema.

## Fuentes y elaboración

Las guías y los ejercicios se preparan a partir de documentación oficial, estándares, manuales y recursos didácticos. El material se redacta de forma propia; no se copian cursos ni soluciones completas. Consulta el [catálogo de fuentes](FUENTES.md) y las referencias incluidas al final de cada guía.

## Idiomas

La documentación está disponible en español y, progresivamente, en inglés. Los archivos en inglés usan el sufijo .en; por ejemplo, GUIA.en.md.

## Estado del proyecto

La estructura y las reglas editoriales están preparadas. La ruta inicial de HTML cubre nivel básico-intermedio con diez ejercicios y un proyecto integrador. CSS ya cuenta con una guía de fundamentos, referencia rápida y cinco ejercicios de práctica. El desarrollo continúa por unidades.

Consulta [PLAN.md](PLAN.md) para ver las fases y [SPEC.md](SPEC.md) para las decisiones del proyecto.

## Requisitos

- Un editor de texto.
- Git, recomendado para mantener cambios e historial.
- El entorno de ejecución o compilador correspondiente al lenguaje que quieras practicar.

La biblioteca se puede consultar sin instalar la CLI. El material esencial debe poder estudiarse sin conexión.

## Uso responsable

Los ejemplos de redes y terminal se orientan al aprendizaje, la administración y las pruebas en sistemas propios o con autorización. No se incluyen prácticas para acceder sin permiso, robar credenciales, evadir controles o causar daño.
