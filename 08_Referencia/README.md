# Referencia

Material para resolver dudas rápidas sin tener que releer una guía completa.

## Contenido previsto

- Glosario técnico.
- Errores frecuentes y sus causas.
- Comparaciones entre lenguajes.
- Diferencias entre motores, plataformas y versiones.
- Comandos, operadores y sintaxis de uso frecuente.
- Tablas de equivalencias.

## Enfoque

La referencia resume; no sustituye las explicaciones completas. Cada entrada debe enlazar a su guía principal.
