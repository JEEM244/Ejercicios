# Herramienta CLI

La CLI será una utilidad opcional escrita en Python para facilitar la consulta de CodeVault desde la terminal. No sustituye los archivos ni añade requisitos para estudiar.

## Funciones previstas

- Mostrar áreas y lenguajes.
- Buscar temas y ejercicios.
- Abrir o mostrar la ruta de un recurso.
- Consultar y actualizar el registro de progreso.
- Validar el formato de IDs.
- Mostrar ayuda y ejemplos de uso.

## Restricciones

- No es necesaria para leer o ejecutar ejercicios.
- No implementa intérpretes ni compiladores.
- No instala runtimes automáticamente.
- No necesita base de datos.
- Debe funcionar con la biblioteca local y manejar errores claramente.

## Estado

Solo se define el alcance. La implementación se realizará después de estabilizar la estructura y el contenido principal.
