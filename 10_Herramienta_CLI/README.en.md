# CLI Tool

The CLI will be an optional Python utility for browsing CodeVault from a terminal. It does not replace the files or add requirements for studying.

## Planned features

- List areas and languages.
- Search topics and exercises.
- Open or display the path to a resource.
- Read and update the progress record.
- Validate exercise ID formats.
- Show help and usage examples.

## Constraints

- Not required to read or run exercises.
- Does not implement interpreters or compilers.
- Does not automatically install runtimes.
- Does not require a database.
- Must work with the local library and handle errors clearly.

## Status

Only the scope is defined. Implementation will begin after the structure and main content are stable.
