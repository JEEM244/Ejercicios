# CodeVault

A personal programming learning and practice library. It brings together guides, quick references, exercises, challenges, and small projects in a structure that can be browsed and extended.

**CodeVault is not a linear course or a web platform.** It is a study repository: open the topic you need, read the explanation, try the code, and return to practice later.

## Goals

- Learn from fundamentals through advanced topics.
- Keep concepts fresh through recurring practice.
- Find syntax, examples, and common mistakes quickly.
- Improve logic, code reading, debugging, and solution design.
- Compare how different languages solve the same problem.
- Build small projects that connect related topics.

## Main areas

See [the English index](INDICE.en.md) or [the Spanish index](INDICE.md).

## How to use it

1. Choose a language, concept, or problem from the index.
2. Read the relevant guide or quick reference.
3. Open an exercise and review its requirements and test cases.
4. Try to solve it before looking at the solution.
5. Compare your result and record anything worth reviewing.

There is no required order. Prerequisites are listed in each topic.

## Language convention

Spanish files use their normal names. English files use the .en suffix, for example SPEC.en.md.

## Sources and authorship

Guides and exercises are prepared using official documentation, standards, manuals, and learning resources. The material is written independently; complete courses and solutions are not copied. See the [reference catalog](FUENTES.en.md) and the sources listed at the end of each guide.

## Project status

The repository structure, project rules, and templates are in place. The first HTML learning path now covers beginner-to-intermediate topics and includes ten exercises and a capstone project. CSS is the next language unit.

See [the roadmap](PLAN.en.md) and [the specification](SPEC.en.md).

## Requirements

A text editor and the runtime or compiler needed by the language you want to practice. Git is recommended. The CLI is optional.

Essential learning material should remain available offline.

## Responsible use

Networking and terminal examples focus on learning, administration, and testing on systems you own or are authorized to use.
