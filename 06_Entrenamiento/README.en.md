# Practice

A place to turn concepts into applicable skills. It does not require a fixed sequence.

## Practice types

- Recall and apply syntax.
- Complete code.
- Solve a problem from scratch.
- Read and interpret code.
- Find and fix bugs.
- Design algorithms.
- Compare solutions across languages.
- Refactor existing code.
- Complete short challenges and assessments.

## Organization

Exercises receive unique IDs and are categorized by language, topic, and difficulty. Solutions are stored separately.
