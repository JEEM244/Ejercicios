# Entrenamiento

Zona de práctica para convertir conceptos en habilidades aplicables. No exige seguir una secuencia fija.

## Tipos de práctica

- Recordar y aplicar sintaxis.
- Completar código.
- Resolver un problema desde cero.
- Leer e interpretar código.
- Encontrar y corregir errores.
- Diseñar algoritmos.
- Comparar soluciones entre lenguajes.
- Refactorizar código existente.
- Resolver retos cortos y evaluaciones.

## Organización

Los ejercicios tendrán IDs únicos y se clasificarán por lenguaje, tema y dificultad. Las soluciones se guardarán por separado.
