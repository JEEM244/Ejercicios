# Fundamentos

Conocimientos que se reutilizan en varios lenguajes. Esta área trabaja cómo analizar un problema y diseñar una solución antes de centrarse en la sintaxis.

## Contenido previsto

- Pensamiento lógico y proposiciones.
- Variables, constantes, tipos y expresiones.
- Operadores y control de flujo.
- Algoritmos y pseudocódigo.
- Descomposición de problemas.
- Funciones y modularidad.
- Estructuras de datos.
- Programación orientada a objetos.
- Paradigmas de programación.
- Complejidad y análisis básico.

## Enfoque

Cada concepto tendrá una explicación general y ejemplos en uno o más lenguajes cuando la comparación aporte valor. Se evitará explicar aquí la sintaxis completa de cada lenguaje.
