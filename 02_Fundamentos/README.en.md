# Fundamentals

Knowledge shared across multiple languages. This area focuses on analyzing a problem and designing a solution before focusing on syntax.

## Planned contents

- Logical thinking and propositions.
- Variables, constants, types, and expressions.
- Operators and control flow.
- Algorithms and pseudocode.
- Problem decomposition.
- Functions and modularity.
- Data structures.
- Object-oriented programming.
- Programming paradigms.
- Complexity and basic analysis.

## Approach

Each concept will have a general explanation and examples in one or more languages when comparison adds value. Full language syntax will be covered in the language sections.
