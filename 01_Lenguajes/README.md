# Lenguajes

CodeVault comienza con once lenguajes y tecnologías. Cada carpeta contendrá guías, referencia rápida, ejemplos, ejercicios, retos y soluciones separadas.

| Lenguaje | Enfoque |
|---|---|
| [HTML](HTML/README.md) | Estructura y semántica de documentos web |
| [CSS](CSS/README.md) | Presentación, diseño y adaptación de interfaces |
| [JavaScript](JavaScript/README.md) | Lógica e interacción en aplicaciones |
| [TypeScript](TypeScript/README.md) | JavaScript con sistema de tipos estático |
| [PHP](PHP/README.md) | Desarrollo del lado del servidor |
| [Python](Python/README.md) | Programación general y automatización |
| [Shell](Shell/README.md) | Bash y PowerShell |
| [C#](CSharp/README.md) | Desarrollo en la plataforma .NET |
| [Kotlin](Kotlin/README.md) | Aplicaciones Kotlin y Android |
| [Lua](Lua/README.md) | Lenguaje ligero y embebible |
| [SQL](SQL/README.md) | Consulta y manipulación de datos relacionales |

## Convenciones

- La guía organiza temas por dependencia, sin obligar a seguir una ruta.
- La referencia rápida es para consultas puntuales.
- Los ejercicios usan IDs únicos.
- Las soluciones permanecen separadas del enunciado.
- Shell distingue Bash y PowerShell; SQL distingue sintaxis común y particularidades de cada motor.
