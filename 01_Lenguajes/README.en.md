# Languages

CodeVault starts with eleven programming languages and technologies. Each directory will contain guides, quick references, examples, exercises, challenges, and separate solutions.

| Language | Focus |
|---|---|
| [HTML](HTML/README.en.md) | Structure and semantics of web documents |
| [CSS](CSS/README.en.md) | Presentation, layout, and responsive interfaces |
| [JavaScript](JavaScript/README.en.md) | Logic and interaction in applications |
| [TypeScript](TypeScript/README.en.md) | JavaScript with a static type system |
| [PHP](PHP/README.en.md) | Server-side development |
| [Python](Python/README.en.md) | General programming and automation |
| [Shell](Shell/README.en.md) | Bash and PowerShell |
| [C#](CSharp/README.en.md) | Development on the .NET platform |
| [Kotlin](Kotlin/README.en.md) | Kotlin and Android applications |
| [Lua](Lua/README.en.md) | Lightweight, embeddable language |
| [SQL](SQL/README.en.md) | Querying and manipulating relational data |

## Conventions

- Guides organize topics by dependency without forcing a learning path.
- Quick references support focused lookups.
- Exercises use unique IDs.
- Solutions remain separate from statements.
- Shell distinguishes Bash and PowerShell; SQL distinguishes common syntax from engine-specific behavior.

See also [Fundamentals](../02_Fundamentos/README.en.md).
