# Solución — JS-007

## Salida esperada

~~~text
Primer elemento: Cuaderno
Cantidad: 3
¿Incluye Cuaderno? true
Elemento retirado: Regla
Material: Cuaderno
~~~

## Explicación

push() agrega el elemento al final y pop() retira el último. length consulta cuántos elementos quedan. for...of permite recorrer los valores sin trabajar directamente con sus índices.
