## Resultado

## Explicación

El operador || devuelve una condición verdadera cuando al menos una de las dos condiciones se cumple:

- La compra alcanza el mínimo.
- El cliente es frecuente.

Por eso el envío es gratis con los valores de ejemplo. Prueba los tres casos indicados en el enunciado para revisar ambas ramas de if.
