# JavaScript

**Status:** four study paths created.  
**Current level:** beginner to intermediate.  
**Focus:** syntax, data, web interaction, modules, and asynchronous programming.

JavaScript lets you write application logic and add interaction to websites. It can also run outside the browser with environments such as Node.js.

## Topics covered

- Variables, types, conversions, operators, conditionals, loops, and functions.
- Arrays, methods, strings, objects, and destructuring.
- Variable scope, reading errors, and debugging.
- DOM, selectors, attributes, classes, nodes, and events.
- Forms, FormData, validation, and basic accessibility.
- Modules with named and default exports and imports.
- JSON serialization, parsing, and error handling.
- Promises, then(), catch(), finally(), async/await, and Promise.all().
- Fetch API, HTTP responses, local or remote JSON, and error handling.

## Organization

The path contains four blocks:

1. **Fundamentals:** JS-001 to JS-006.
2. **Data structures and debugging:** JS-007 to JS-012.
3. **DOM and events:** JS-013 to JS-018.
4. **Modules and asynchronous programming:** JS-019 to JS-024.

Each exercise includes a bilingual prompt, starter files, and a separate solution. JS-001 to JS-012 and JS-021 to JS-023 can run with Node.js. JS-013 to JS-020 and JS-024 require a browser; exercises using modules or Fetch must be opened through a local HTTP server. No frameworks or external packages are required.

## Workflow

1. Read the guide for the block.
2. Open the prompt and starter files.
3. Complete the TODO instructions before opening the solution.
4. Run each practice in the required environment.
5. Change the test data and inspect errors.
6. Compare your result with the solution.

const is used by default and let is used when a value must change. var is introduced as older syntax, not as the recommended option.

## Next stage

After practicing these foundations, review the pages in a real browser and continue with TypeScript or projects that combine the DOM, modules, and APIs.
