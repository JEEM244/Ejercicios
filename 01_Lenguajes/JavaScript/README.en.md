# JavaScript

**Status:** fundamentals, data structures, and DOM paths created.  
**Current level:** beginner-intermediate.  
**Focus:** syntax, data, debugging, and web page interaction.

JavaScript lets you write application logic and add interaction to websites. It can also run outside the browser with environments such as Node.js.

## Topics covered

- Running code in a browser and with Node.js.
- Variables, types, conversions, and operators.
- Conditionals, loops, and functions.
- Arrays, indexes, and iteration.
- forEach(), map(), filter(), find(), and reduce().
- String methods, objects, properties, and nested structures.
- Arrays of objects and destructuring.
- Global, function, and block scope.
- Debugging, reading errors, and breakpoints.
- DOM: selectors, text, classes, attributes, and creating elements.
- click, input, change, and submit events.
- Forms, FormData, and browser validation.
- Basic accessibility and safe use of textContent.

## Organization

The path contains three study blocks:

1. **Fundamentals:** JS-001 to JS-006.
2. **Data structures and debugging:** JS-007 to JS-012.
3. **DOM and events:** JS-013 to JS-018.

Each exercise includes a prompt in Spanish and English, a starter project, and a separate solution. The first twelve exercises use general JavaScript and can run with Node.js. DOM exercises must be opened in a browser because they use document and HTML elements. No frameworks or external packages are required.

## Workflow

1. Read the topic guide.
2. Open the prompt and starter file.
3. Complete the TODO instructions or fix the reported errors.
4. For JS-001 to JS-012, run the JavaScript file with Node.js or in the browser console.
5. For JS-013 to JS-018, open index.html in a browser.
6. Try different data and actions.
7. Compare with the solution only after attempting the task.

const is used by default and let is used when a value must change. var is introduced as older syntax, not as the recommended option.
