# JS-012 — Depurar un programa

- **Tema:** lectura de errores, alcance de bloque y depuración paso a paso.
- **Nivel:** básico-intermedio.
- **Requisitos:** JS-007 a JS-011.
- **Tipo:** ejercicio de depuración.

## Objetivo

Encontrar errores de lógica y de referencia, corregirlos y comprobar el resultado con los mismos datos de entrada.

## Enunciado

El siguiente programa debe calcular el total de una lista de precios, crear una etiqueta de estudiante y generar un aviso. Tiene tres errores intencionales. Ejecútalo y corrige un problema a la vez.

## Requisitos

- [ ] Revisa por qué el total calculado no coincide con la suma de los precios.
- [ ] Lee el error que aparece al crear la etiqueta y localiza el nombre incorrecto.
- [ ] Revisa el alcance de la variable mensaje dentro de crearAviso().
- [ ] Usa console.log() para comprobar valores intermedios.
- [ ] Corrige los tres errores sin cambiar los datos originales.
- [ ] Ejecuta otra vez el programa y compara la salida con el resultado esperado.

## Archivo inicial

Trabaja en [ejercicio.js](JS-012/ejercicio.js). El archivo contiene errores intencionales.

## Resultado esperado

~~~text
Total: 60
Alumno: Mara
Aviso: Revisa tus ejercicios.
~~~

## Método de trabajo

No cambies todo al mismo tiempo. Primero corrige la suma; vuelve a ejecutar. Después arregla el nombre que provoca ReferenceError; vuelve a ejecutar. Finalmente corrige el alcance de mensaje.
