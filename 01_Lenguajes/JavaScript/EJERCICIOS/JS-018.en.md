# JS-018 — Validate a form

- **Topic:** HTML constraints, `checkValidity()`, and `reportValidity()`.
- **Level:** early intermediate.
- **Prerequisites:** JS-017.
- **Type:** guided practice.

## Goal

Combine HTML constraints with JavaScript to check a form before displaying a confirmation.

## Prompt

Complete the practice contact form. The name must contain at least three characters, the email must have an email format, and the message cannot be empty. The document uses `novalidate` so you can control validation from JavaScript.

## Requirements

- [ ] Select the form and status area.
- [ ] Listen for the `submit` event.
- [ ] Cancel the default submission.
- [ ] Check the fields with `checkValidity()`.
- [ ] When errors exist, call `reportValidity()` and display a notice.
- [ ] When all fields are valid, display a confirmation using `textContent`.
- [ ] Do not send data to a server or claim that it was saved.

## Starter files

Open [index.html](JS-018/index.html) and complete [app.js](JS-018/app.js).

## Tests

- Leave a field empty: the form should report the problem.
- Enter a two-letter name: it should be invalid.
- Enter an email without a valid format: it should be invalid.
- Complete every field correctly: the local confirmation should appear.

## Important

Browser validation improves the user experience, but it does not protect data in a real application. Every server must validate the data it receives again.
