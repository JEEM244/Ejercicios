# JS-012 — Debug a program

- **Topic:** reading errors, block scope, and step-by-step debugging.
- **Level:** beginner-intermediate.
- **Requirements:** JS-007 to JS-011.
- **Type:** debugging exercise.

## Objective

Find logic and reference errors, fix them, and check the result using the same input data.

## Task

The following program should calculate the total of a price list, create a student label, and generate a notice. It contains three intentional errors. Run it and fix one problem at a time.

## Requirements

- [ ] Check why the calculated total does not match the sum of the prices.
- [ ] Read the error shown when creating the label and locate the incorrect name.
- [ ] Check the scope of the mensaje variable inside crearAviso().
- [ ] Use console.log() to inspect intermediate values.
- [ ] Fix all three errors without changing the original data.
- [ ] Run the program again and compare the output with the expected result.

## Starter file

Work in [ejercicio.js](JS-012/ejercicio.js). The file contains intentional errors.

## Expected result

~~~text
Total: 60
Alumno: Mara
Aviso: Revisa tus ejercicios.
~~~

## Workflow

Do not change everything at once. First fix the sum and run the program again. Then fix the name that causes ReferenceError and run it again. Finally, fix the scope of mensaje.
