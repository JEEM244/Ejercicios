# JS-003 — Operadores y cálculo de totales

- **Tema:** operaciones aritméticas y orden de cálculo.
- **Nivel:** básico.
- **Requisitos:** JS-001 y JS-002.
- **Tipo:** ejercicio práctico.

## Objetivo

Utilizar multiplicación, porcentajes y resta para calcular el total de una compra.

## Enunciado

Calcula el importe de una compra con precio unitario, cantidad y descuento. Muestra el subtotal, el ahorro y el total final con dos decimales.

## Requisitos

- [ ] Calcula el subtotal multiplicando precio por cantidad.
- [ ] Calcula el descuento multiplicando el subtotal por el porcentaje.
- [ ] Resta el descuento al subtotal.
- [ ] Muestra los tres resultados con toFixed(2).
- [ ] No escribas manualmente los resultados finales.

## Archivo inicial

Completa [ejercicio.js](JS-003/ejercicio.js).

## Resultado esperado

Con los valores de ejemplo, el subtotal es 269.70, el ahorro es 26.97 y el total es 242.73.

## Comprobación

Cambia la cantidad o el descuento y confirma que todos los resultados se recalculan.
