# JS-021 — Convertir y validar datos JSON

- **Tema:** JSON.stringify(), JSON.parse() y manejo de errores.
- **Nivel:** intermedio inicial.
- **Requisitos:** objetos, arreglos y try...catch.
- **Tipo:** práctica guiada.

## Objetivo

Convertir un objeto a texto JSON y recuperar los datos mediante un proceso de análisis.

## Enunciado

Completa un programa que representa un registro de estudiante. Debe convertir el objeto a JSON, mostrar el texto generado y recuperar los valores con `JSON.parse()`. Después, debe manejar un texto JSON mal formado.

## Requisitos

- [ ] Crea un objeto con nombre, grupo y una lista de materias.
- [ ] Convierte el objeto a texto con `JSON.stringify()`.
- [ ] Usa sangría de dos espacios para que el texto sea legible.
- [ ] Recupera el objeto con `JSON.parse()`.
- [ ] Muestra el nombre y el grupo recuperados.
- [ ] Intenta analizar un texto JSON inválido dentro de `try...catch`.
- [ ] Muestra un mensaje claro cuando ocurra el error.

## Archivo inicial

Completa [ejercicio.js](JS-021/ejercicio.js) y ejecútalo:

~~~bash
node ejercicio.js
~~~

## Pruebas

- Comprueba que el texto JSON incluya las tres propiedades.
- Comprueba que el objeto recuperado conserve los datos.
- Cambia el texto inválido por otro texto mal formado y confirma que el programa no termina sin manejar el error.
