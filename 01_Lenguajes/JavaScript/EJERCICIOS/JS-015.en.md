# JS-015 — Live text preview

- **Topic:** the `input` event, `value`, and `textContent`.
- **Level:** beginner-intermediate.
- **Prerequisites:** JS-013 and JS-014.
- **Type:** guided practice.

## Goal

Read a field while its value changes and display a live preview.

## Prompt

The page contains a text field with a 60-character limit. Complete the code to show what is being typed and update a character counter whenever the field changes.

## Requirements

- [ ] Select the field, preview, and counter.
- [ ] Register the `input` event on the field.
- [ ] Read the current value with `value`.
- [ ] Display the text in the preview using `textContent`.
- [ ] Update the character count.
- [ ] When the field is empty, display "Your text will appear here".

## Starter files

Open [index.html](JS-015/index.html) and complete [app.js](JS-015/app.js).

## Tests

- Type "CodeVault": the preview should display that text and the counter should show 9.
- Clear the field: the initial message should return and the counter should show 0.
- Paste several words and confirm that the counter updates.
