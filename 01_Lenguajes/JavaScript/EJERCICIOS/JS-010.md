# JS-010 — Crear y modificar objetos

- **Tema:** propiedades, notación de punto, corchetes, objetos anidados y métodos.
- **Nivel:** básico-intermedio.
- **Requisitos:** JS-001 a JS-009.
- **Tipo:** ejercicio práctico.

## Objetivo

Representar información relacionada en un objeto, consultar sus propiedades y crear un método sencillo.

## Enunciado

Crea un objeto para representar un libro de una pequeña biblioteca. Guarda su título, autor, disponibilidad y una categoría. Después cambia su disponibilidad y crea un método que genere una descripción.

## Requisitos

- [ ] Declara un objeto llamado libro con título, autor y disponible.
- [ ] Agrega una propiedad categoria.
- [ ] Consulta el título con notación de punto.
- [ ] Consulta el autor usando una variable y notación de corchetes.
- [ ] Cambia disponible a false.
- [ ] Agrega un objeto anidado editorial con un nombre.
- [ ] Crea un método descripcion() que devuelva un texto usando propiedades del objeto.
- [ ] Muestra la descripción y las propiedades principales.

## Archivo inicial

Completa [ejercicio.js](JS-010/ejercicio.js).

## Resultado esperado

El libro debe mostrar título "El principito", autor "Antoine de Saint-Exupéry", disponibilidad false, categoría "Novela" y editorial "Rey".

## Comprobación

Cambia el nombre del libro o del autor y verifica que la descripción use los nuevos datos.
