# JS-015 — Vista previa de texto

- **Tema:** evento `input`, propiedad `value` y `textContent`.
- **Nivel:** básico-intermedio.
- **Requisitos:** JS-013 y JS-014.
- **Tipo:** práctica guiada.

## Objetivo

Leer un campo mientras cambia su valor y mostrar una vista previa en tiempo real.

## Enunciado

La página contiene un campo de texto con un máximo de 60 caracteres. Completa el código para mostrar lo que se escribe y actualizar un contador de caracteres cada vez que cambia el campo.

## Requisitos

- [ ] Selecciona el campo, la vista previa y el contador.
- [ ] Registra el evento `input` en el campo.
- [ ] Lee el valor actual mediante `value`.
- [ ] Muestra el texto en la vista previa mediante `textContent`.
- [ ] Actualiza el número de caracteres.
- [ ] Si el campo está vacío, muestra el texto "Tu texto aparecerá aquí".

## Archivo inicial

Abre [index.html](JS-015/index.html) y completa [app.js](JS-015/app.js).

## Pruebas

- Escribe "CodeVault": la vista previa debe mostrar ese texto y el contador 9.
- Borra el contenido: debe aparecer el mensaje inicial y el contador 0.
- Pega varias palabras y confirma que el contador se actualice.
