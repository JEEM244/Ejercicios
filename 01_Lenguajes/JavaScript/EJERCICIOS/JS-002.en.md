# JS-002 — Data types and conversions

- **Topic:** string, number, boolean, typeof, and Number().
- **Level:** beginner.
- **Requirements:** JS-001 and variables.
- **Type:** practical exercise.

## Objective

Identify a value's type and convert numeric text to a number before performing an operation.

## Task

A product's price and quantity are stored as text. Convert both values to numbers, calculate the subtotal, and display the original data type.

## Requirements

- [ ] Keep precioTexto and unidadesTexto as strings.
- [ ] Convert both values with Number().
- [ ] Use typeof to display the type of precioTexto.
- [ ] Calculate the subtotal using the converted values.
- [ ] Use Number.isNaN() to check whether price conversion failed.

## Starter file

Complete [ejercicio.js](JS-002/ejercicio.js).

## Expected result

With the sample data: product Cuaderno, price 125, quantity 3, and subtotal 375. The original price type should be string and the conversion should not produce NaN.

## Check your work

Change precioTexto to "dato" and observe what happens. Then restore a valid numeric value.
