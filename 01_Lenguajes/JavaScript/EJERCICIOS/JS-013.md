# JS-013 — Seleccionar y actualizar elementos

- **Tema:** DOM, selectores y contenido de texto.
- **Nivel:** básico-intermedio.
- **Requisitos:** HTML básico y variables de JavaScript.
- **Tipo:** práctica guiada.

## Objetivo

Encontrar elementos del HTML desde JavaScript y cambiar su contenido de forma controlada.

## Enunciado

La página inicial muestra un título, un párrafo de estado y un botón. Completa el archivo JavaScript para que, al activar el botón, cambien el título y el mensaje.

## Requisitos

- [ ] Selecciona el título mediante su ID.
- [ ] Selecciona el mensaje y el botón.
- [ ] Registra un listener para el evento \`click\`.
- [ ] Cambia el contenido con \`textContent\`.
- [ ] Cambia el texto del botón después de activarlo.
- [ ] Comprueba que los selectores coincidan con los IDs del HTML.

## Archivo inicial

Abre [index.html](JS-013/index.html) en el navegador y completa [app.js](JS-013/app.js).

## Resultado esperado

Al presionar el botón, la página debe mostrar el título **"¡JavaScript está conectado!"** y un mensaje que confirme que el DOM fue actualizado. El botón debe cambiar a **"Actualizado"**.

## Pruebas

1. Abre el archivo antes de modificarlo y observa el contenido inicial.
2. Presiona el botón y comprueba los tres cambios.
3. Revisa la consola del navegador para confirmar que no hay errores.
