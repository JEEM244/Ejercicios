# JS-009 — Clean and inspect strings

- **Topic:** trim(), toLowerCase(), toUpperCase(), includes(), and slice().
- **Level:** beginner-intermediate.
- **Requirements:** variables and methods.
- **Type:** practical exercise.

## Objective

Clean received text, normalize it, and extract information without changing the original string.

## Task

A form receives a topic name with extra spaces and mixed letter casing. Generate a clean version, an uppercase version, and check whether it includes the word "javascript".

## Requirements

- [ ] Keep the original string.
- [ ] Use trim() to remove spaces at the beginning and end.
- [ ] Use toLowerCase() to create a normalized version.
- [ ] Use toUpperCase() to create an uppercase version.
- [ ] Use includes() to check whether it contains "javascript".
- [ ] Use slice() to extract the first word.

## Starter file

Complete [ejercicio.js](JS-009/ejercicio.js).

## Expected result

The clean version should be "JavaScript Web"; the normalized version "javascript web"; the uppercase version "JAVASCRIPT WEB"; the search should return true and the first word should be "JavaScript".

## Check your work

Try another string, including extra spaces and a topic that does not contain the searched word.
