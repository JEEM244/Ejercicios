# JS-008 — Transformar y filtrar datos

- **Tema:** map(), filter(), find() y reduce().
- **Nivel:** básico-intermedio.
- **Requisitos:** JS-007 y funciones.
- **Tipo:** ejercicio práctico.

## Objetivo

Elegir el método adecuado para transformar una lista, filtrar elementos, encontrar una coincidencia y calcular un total.

## Enunciado

Tienes una lista de calificaciones. Obtén una lista con puntos extra, otra con las calificaciones aprobatorias, encuentra la primera calificación menor a 60 y calcula el promedio.

## Requisitos

- [ ] Conserva el arreglo original de calificaciones.
- [ ] Usa map() para crear un arreglo nuevo que sume 5 puntos a cada calificación.
- [ ] Usa filter() para conservar calificaciones de 70 o más.
- [ ] Usa find() para buscar la primera calificación menor a 60.
- [ ] Usa reduce() para sumar las calificaciones originales.
- [ ] Calcula y muestra el promedio sin modificar el arreglo original.

## Archivo inicial

Completa [ejercicio.js](JS-008/ejercicio.js).

## Resultado esperado

Con las calificaciones de ejemplo, el arreglo con puntos extra debe ser [90, 67, 99, 75, 63], las aprobatorias [85, 94, 70], la primera menor a 60 debe ser 58 y el promedio 73.8.

## Comprobación

Cambia una calificación y verifica que los cuatro resultados se actualicen.
