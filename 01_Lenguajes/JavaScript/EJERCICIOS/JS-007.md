# JS-007 — Crear y recorrer arreglos

- **Tema:** arreglos, índices, length, push(), pop() y for...of.
- **Nivel:** básico-intermedio.
- **Requisitos:** JS-001 a JS-006.
- **Tipo:** ejercicio práctico.

## Objetivo

Guardar varios elementos en un arreglo, modificar la lista y recorrerla para mostrar su contenido.

## Enunciado

Crea una lista de materiales para estudiar. Agrega un elemento, consulta uno de sus valores, comprueba si contiene un artículo y retira el último elemento.

## Requisitos

- [ ] Declara un arreglo llamado materiales con dos elementos iniciales.
- [ ] Agrega "Regla" usando push().
- [ ] Muestra el primer elemento y la cantidad de elementos con length.
- [ ] Comprueba si la lista contiene "Cuaderno" usando includes().
- [ ] Retira el último elemento con pop() y muestra cuál fue.
- [ ] Recorre la lista restante con for...of.

## Archivo inicial

Completa [ejercicio.js](JS-007/ejercicio.js).

## Resultado esperado

La lista inicial contiene Cuaderno y Pluma. Después de agregar Regla, tiene tres elementos. Al retirar el último, Regla debe aparecer como eliminado y la lista final debe contener Cuaderno y Pluma.

## Comprobación

Cambia los elementos iniciales y agrega otro artículo. Comprueba cómo cambian length y la salida del ciclo.
