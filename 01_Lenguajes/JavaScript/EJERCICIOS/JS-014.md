# JS-014 — Contador con eventos

- **Tema:** \`addEventListener()\`, clics y estado.
- **Nivel:** básico-intermedio.
- **Requisitos:** JS-013.
- **Tipo:** práctica guiada.

## Objetivo

Usar distintos botones para modificar una variable y reflejar su valor en la página.

## Enunciado

Completa un contador con botones para aumentar, disminuir y reiniciar. El valor debe actualizarse sin recargar la página.

## Requisitos

- [ ] Selecciona el valor y los tres botones.
- [ ] Declara una variable para guardar el contador.
- [ ] Usa \`addEventListener()\` para escuchar los clics.
- [ ] Aumenta el contador en uno con el botón correspondiente.
- [ ] Disminuye el contador en uno con el segundo botón.
- [ ] Restablece el contador a cero con el tercer botón.
- [ ] Actualiza el valor de la página después de cada operación.

## Archivo inicial

Abre [index.html](JS-014/index.html) y completa [app.js](JS-014/app.js).

## Pruebas

- Aumenta el valor tres veces: debe mostrar 3.
- Disminúyelo una vez: debe mostrar 2.
- Reinícialo: debe mostrar 0.
- Comprueba que la página no se recargue.
