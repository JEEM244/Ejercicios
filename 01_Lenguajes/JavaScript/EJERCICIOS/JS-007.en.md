# JS-007 — Create and iterate over arrays

- **Topic:** arrays, indexes, length, push(), pop(), and for...of.
- **Level:** beginner-intermediate.
- **Requirements:** JS-001 to JS-006.
- **Type:** practical exercise.

## Objective

Store several items in an array, modify the list, and iterate over it to display its contents.

## Task

Create a list of study supplies. Add an item, inspect one of its values, check whether it contains an item, and remove the last item.

## Requirements

- [ ] Declare an array named materiales with two initial items.
- [ ] Add "Regla" using push().
- [ ] Display the first item and the number of items with length.
- [ ] Check whether the list contains "Cuaderno" using includes().
- [ ] Remove the last item with pop() and display what was removed.
- [ ] Iterate over the remaining list with for...of.

## Starter file

Complete [ejercicio.js](JS-007/ejercicio.js).

## Expected result

The initial list contains Cuaderno and Pluma. After adding Regla, it has three items. After removing the last item, Regla should be displayed as removed and the final list should contain Cuaderno and Pluma.

## Check your work

Change the initial items and add another supply. Check how length and the loop output change.
