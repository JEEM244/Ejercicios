# JS-009 — Limpiar y consultar cadenas

- **Tema:** trim(), toLowerCase(), toUpperCase(), includes() y slice().
- **Nivel:** básico-intermedio.
- **Requisitos:** variables y métodos.
- **Tipo:** ejercicio práctico.

## Objetivo

Limpiar texto recibido, normalizarlo y extraer información sin modificar la cadena original.

## Enunciado

Un formulario recibe el nombre de un tema con espacios adicionales y letras mezcladas. Genera una versión limpia, otra en mayúsculas y comprueba si incluye la palabra "javascript".

## Requisitos

- [ ] Conserva la cadena original.
- [ ] Usa trim() para quitar espacios al inicio y al final.
- [ ] Usa toLowerCase() para generar una versión normalizada.
- [ ] Usa toUpperCase() para crear una versión en mayúsculas.
- [ ] Usa includes() para comprobar si contiene "javascript".
- [ ] Usa slice() para extraer la primera palabra.

## Archivo inicial

Completa [ejercicio.js](JS-009/ejercicio.js).

## Resultado esperado

La versión limpia debe ser "JavaScript Web"; la normalizada "javascript web"; la versión en mayúsculas "JAVASCRIPT WEB"; la búsqueda debe devolver true y la primera palabra "JavaScript".

## Comprobación

Prueba con otro texto, con espacios extra y con un tema que no incluya la palabra buscada.
