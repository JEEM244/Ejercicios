# JS-019 — Export and import functions

- **Topic:** modules, named exports, and imports.
- **Level:** early intermediate.
- **Prerequisites:** JS-006 and basic HTML.
- **Type:** guided practice.

## Goal

Move calculation functions into one file and reuse them from another module.

## Prompt

The page contains two numeric fields. Complete the operations module and the main file to calculate the sum and average of the values.

## Requirements

- [ ] In `modulos/operaciones.js`, export the functions `sumar(a, b)` and `promedio(a, b)`.
- [ ] Import both functions in `app.js` using named imports.
- [ ] Read the values from the HTML fields.
- [ ] Convert the inputs to numbers.
- [ ] Check that the inputs are valid numbers.
- [ ] Display the results on the page using `textContent`.
- [ ] Keep calculation functions outside the main file.

## Starter files

Open [index.html](JS-019/index.html) from a local HTTP server and complete:
- [app.js](JS-019/app.js)
- [operations.js](JS-019/modulos/operaciones.js)

## Tests

- Use 10 and 20: sum 30 and average 15.
- Use -4 and 8: sum 4 and average 2.
- Leave a field empty: the page should display a notice and must not show incorrect results.
