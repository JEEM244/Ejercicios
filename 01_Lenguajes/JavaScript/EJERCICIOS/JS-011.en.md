# JS-011 — Process an array of objects

- **Topic:** arrays of objects, map(), filter(), find(), and reduce().
- **Level:** beginner-intermediate.
- **Requirements:** JS-007 to JS-010.
- **Type:** practical exercise.

## Objective

Work with a collection of records, select items, and calculate a value from their properties.

## Task

A small inventory stores products as objects inside an array. Get the names of all products, filter items with low stock, find one by name, and calculate the total inventory value.

## Requirements

- [ ] Keep the productos array.
- [ ] Use map() to create an array of names.
- [ ] Use filter() to find products with stock below 5.
- [ ] Use find() to search for the "Teclado" product.
- [ ] Use reduce() to sum price multiplied by stock for every product.
- [ ] Do not directly change the objects in the original array.

## Starter file

Complete [ejercicio.js](JS-011/ejercicio.js).

## Expected result

Names: Mouse, Teclado, Monitor. Low stock: Mouse and Teclado. Teclado should be found. The total inventory value should be 5,550.

## Check your work

Change a product's stock and check how the total value and low-stock list change.
