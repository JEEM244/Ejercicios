# Ejercicios de JavaScript

Ruta inicial para practicar fundamentos. Cada ejercicio incluye un enunciado, un archivo inicial y una solución independiente.

## Requisitos

- JavaScript básico explicado en [GUIA.md](../GUIA.md).
- Node.js instalado o un navegador con consola de desarrollador.
- Editor de texto.

Para ejecutar un ejercicio desde la terminal, entra a la carpeta correspondiente y usa:

~~~bash
node ejercicio.js
~~~

## Forma de trabajo

1. Lee el objetivo y los requisitos.
2. Abre el archivo inicial dentro de la carpeta del ejercicio.
3. Completa los TODO sin copiar la solución.
4. Ejecuta el archivo y compara la salida con el resultado esperado.
5. Prueba al menos un valor diferente.
6. Consulta la solución solo después de intentarlo.

Las soluciones se encuentran en [SOLUCIONES](../SOLUCIONES/). No necesitas instalar librerías ni crear un proyecto adicional.
