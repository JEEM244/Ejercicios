# JS-018 — Validar un formulario

- **Tema:** restricciones HTML, \`checkValidity()\` y \`reportValidity()\`.
- **Nivel:** intermedio inicial.
- **Requisitos:** JS-017.
- **Tipo:** práctica guiada.

## Objetivo

Combinar las restricciones de HTML con JavaScript para revisar un formulario antes de mostrar una confirmación.

## Enunciado

Completa el formulario de contacto de práctica. El nombre debe tener al menos 3 caracteres, el correo debe tener formato de correo y el mensaje no puede estar vacío. El documento tiene \`novalidate\` para que puedas controlar la comprobación desde JavaScript.

## Requisitos

- [ ] Selecciona el formulario y el área de estado.
- [ ] Escucha el evento \`submit\`.
- [ ] Cancela el envío predeterminado.
- [ ] Comprueba los campos con \`checkValidity()\`.
- [ ] Cuando existan errores, llama a \`reportValidity()\` y muestra un aviso.
- [ ] Cuando todos los campos sean válidos, muestra una confirmación usando \`textContent\`.
- [ ] No envíes los datos a un servidor ni afirmes que fueron guardados.

## Archivo inicial

Abre [index.html](JS-018/index.html) y completa [app.js](JS-018/app.js).

## Pruebas

- Deja un campo vacío: el formulario debe señalar el problema.
- Escribe un nombre de dos letras: debe ser inválido.
- Escribe un correo sin formato válido: debe ser inválido.
- Completa todos los campos correctamente: debe aparecer la confirmación local.

## Importante

La validación del navegador mejora la experiencia, pero no protege los datos de una aplicación real. Todo servidor debe validar nuevamente los datos que recibe.
