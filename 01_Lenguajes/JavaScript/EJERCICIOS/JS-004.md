# JS-004 — Condicionales y operadores lógicos

- **Tema:** if, else, comparación y OR lógico.
- **Nivel:** básico.
- **Requisitos:** JS-001 a JS-003.
- **Tipo:** ejercicio práctico.

## Objetivo

Tomar una decisión usando una condición y combinar dos criterios con el operador lógico OR (||).

## Enunciado

Un comercio ofrece envío gratis cuando la compra alcanza el importe mínimo o cuando el cliente pertenece al programa de clientes frecuentes. En caso contrario, el envío cuesta 80.

## Requisitos

- [ ] Conserva los valores de compra, compra mínima y tipo de cliente.
- [ ] Usa if y else para elegir el costo de envío.
- [ ] Combina las condiciones con ||.
- [ ] Muestra si el envío es gratis o tiene costo.
- [ ] Muestra el costo de envío con dos decimales.

## Archivo inicial

Completa [ejercicio.js](JS-004/ejercicio.js).

## Resultado esperado

Con los valores de ejemplo, el envío es gratis porque el cliente es frecuente, aunque la compra no alcanza el mínimo.

## Comprobación

Prueba estos casos: cliente frecuente con compra baja, cliente no frecuente con compra alta y cliente no frecuente con compra baja.
