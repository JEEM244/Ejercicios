# JS-016 — Crear elementos de una lista

- **Tema:** `submit`, `preventDefault()`, `createElement()` y `append()`.
- **Nivel:** intermedio inicial.
- **Requisitos:** JS-013 a JS-015.
- **Tipo:** práctica guiada.

## Objetivo

Crear elementos HTML desde JavaScript a partir del texto de un formulario.

## Enunciado

Completa una lista de tareas local. Al enviar el formulario, el programa debe leer el campo, crear un elemento `li` y agregarlo a la lista. No debe recargar la página.

## Requisitos

- [ ] Selecciona el formulario, el campo y la lista.
- [ ] Escucha el evento `submit` del formulario.
- [ ] Cancela el envío predeterminado con `preventDefault()`.
- [ ] Limpia los espacios del valor con `trim()`.
- [ ] No agregues elementos cuando el campo esté vacío.
- [ ] Crea un elemento `li` con `document.createElement()`.
- [ ] Coloca el texto con `textContent` y agrega el elemento con `append()`.
- [ ] Limpia el campo y devuelve el foco a la entrada.

## Archivo inicial

Abre [index.html](JS-016/index.html) y completa [app.js](JS-016/app.js).

## Pruebas

1. Agrega dos tareas distintas: deben aparecer dos elementos.
2. Envía el campo vacío: no debe aparecer una tarea vacía.
3. Escribe texto con espacios al principio y al final: deben eliminarse esos espacios.
4. Comprueba que el documento no se recargue.
