# JS-006 — Functions and return values

- **Topic:** declaring functions, parameters, and return.
- **Level:** beginner.
- **Requirements:** JS-001 to JS-005.
- **Type:** practical exercise.

## Objective

Create reusable functions that receive values and return results.

## Task

Create one function that calculates a rectangle's area and another that builds a summary with a person's name and the calculated area.

## Requirements

- [ ] Declare calcularArea(ancho, alto).
- [ ] The function must return ancho multiplied by alto using return.
- [ ] Declare crearResumen(nombre, ancho, alto).
- [ ] Use calcularArea() inside crearResumen().
- [ ] Return a template string with the name and area.
- [ ] Call both functions and display their results.

## Starter file

Complete [ejercicio.js](JS-006/ejercicio.js).

## Expected result

With the sample values, the area should be 15 and the summary should mention Alex and the result 15.

## Check your work

Try the function with another width and height. Confirm that the result changes without editing the functions.
