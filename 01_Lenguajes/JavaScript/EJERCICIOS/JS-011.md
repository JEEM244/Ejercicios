# JS-011 — Procesar un arreglo de objetos

- **Tema:** arreglos de objetos, map(), filter(), find() y reduce().
- **Nivel:** básico-intermedio.
- **Requisitos:** JS-007 a JS-010.
- **Tipo:** ejercicio práctico.

## Objetivo

Trabajar con una colección de registros, seleccionar elementos y calcular un valor a partir de sus propiedades.

## Enunciado

Un pequeño inventario guarda productos como objetos dentro de un arreglo. Obtén los nombres de todos los productos, filtra los que tienen existencias bajas, encuentra uno por su nombre y calcula el valor total del inventario.

## Requisitos

- [ ] Conserva el arreglo productos.
- [ ] Usa map() para crear un arreglo con los nombres.
- [ ] Usa filter() para encontrar productos con existencias menores a 5.
- [ ] Usa find() para buscar el producto "Teclado".
- [ ] Usa reduce() para sumar precio por existencia de cada producto.
- [ ] No cambies directamente los objetos del arreglo original.

## Archivo inicial

Completa [ejercicio.js](JS-011/ejercicio.js).

## Resultado esperado

Nombres: Mouse, Teclado, Monitor. Existencias bajas: Mouse y Teclado. El Teclado debe encontrarse correctamente. El valor total del inventario debe ser 5,550.

## Comprobación

Modifica el stock de un producto y comprueba cómo cambia el valor total y la lista de existencias bajas.
