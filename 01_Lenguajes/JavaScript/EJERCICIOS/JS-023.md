# JS-023 — Usar async, await y Promise.all

- **Tema:** funciones asíncronas, await, try...catch y Promise.all().
- **Nivel:** intermedio.
- **Requisitos:** JS-022.
- **Tipo:** práctica guiada.

## Objetivo

Reescribir una consulta basada en promesas usando async/await y ejecutar dos tareas independientes en paralelo.

## Enunciado

Un panel necesita cargar los nombres de dos grupos de ejemplo. Completa dos funciones que simulan consultas con tiempos distintos y una función principal que espere ambas operaciones.

## Requisitos

- [ ] Crea una función `cargarGrupo(nombre, demora)` que devuelva una promesa.
- [ ] Usa `setTimeout()` para simular la duración.
- [ ] Crea una función `iniciarPanel()` declarada con `async`.
- [ ] Ejecuta las dos consultas con `Promise.all()`.
- [ ] Usa `await` para recibir los resultados.
- [ ] Maneja errores con `try...catch`.
- [ ] Usa `finally` para mostrar que el proceso terminó.
- [ ] No encadenes las dos consultas de forma secuencial si no dependen entre sí.

## Archivo inicial

Completa [ejercicio.js](JS-023/ejercicio.js) y ejecútalo:

~~~bash
node ejercicio.js
~~~

## Pruebas

- Las dos consultas deben aparecer en el resultado final.
- Cambia el tiempo de espera de cada grupo.
- Fuerza un rechazo en una consulta y comprueba que el bloque catch recibe el error.
