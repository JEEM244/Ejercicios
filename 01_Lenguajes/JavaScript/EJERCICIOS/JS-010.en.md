# JS-010 — Create and update objects

- **Topic:** properties, dot notation, bracket notation, nested objects, and methods.
- **Level:** beginner-intermediate.
- **Requirements:** JS-001 to JS-009.
- **Type:** practical exercise.

## Objective

Represent related information in an object, inspect its properties, and create a simple method.

## Task

Create an object representing a book in a small library. Store its title, author, availability, and a category. Then change its availability and create a method that builds a description.

## Requirements

- [ ] Declare an object named libro with title, author, and disponible properties.
- [ ] Add a categoria property.
- [ ] Read the title with dot notation.
- [ ] Read the author using a variable and bracket notation.
- [ ] Change disponible to false.
- [ ] Add a nested editorial object with a name.
- [ ] Create a descripcion() method that returns text using object properties.
- [ ] Display the description and main properties.

## Starter file

Complete [ejercicio.js](JS-010/ejercicio.js).

## Expected result

The book should display title "El principito", author "Antoine de Saint-Exupéry", availability false, category "Novela", and publisher "Rey".

## Check your work

Change the book title or author and verify that the description uses the new data.
