# JS-022 — Encadenar promesas

- **Tema:** Promise, then(), catch() y finally().
- **Nivel:** intermedio inicial.
- **Requisitos:** funciones, condicionales y funciones flecha.
- **Tipo:** práctica guiada.

## Objetivo

Crear una operación asíncrona simulada y procesar su resultado con una cadena de promesas.

## Enunciado

Completa una función `consultarEstado()` que simula una consulta. Debe devolver una promesa que se cumple o se rechaza después de un pequeño retraso.

## Requisitos

- [ ] Crea una función `consultarEstado(correcto)`.
- [ ] La función debe devolver una instancia de `Promise`.
- [ ] Usa `setTimeout()` para simular una espera.
- [ ] Si `correcto` es true, llama a `resolve()` con un mensaje.
- [ ] Si es false, llama a `reject()` con un objeto Error.
- [ ] Consume la promesa con `then()`, `catch()` y `finally()`.
- [ ] Ejecuta una prueba correcta y otra que produzca un rechazo.

## Archivo inicial

Completa [ejercicio.js](JS-022/ejercicio.js) y ejecútalo:

~~~bash
node ejercicio.js
~~~

## Pruebas

- La consulta correcta debe mostrar el mensaje resuelto.
- La consulta fallida debe mostrar el mensaje de error.
- El bloque finally debe ejecutarse en ambos casos.

## Nota

El temporizador solo simula una operación asíncrona. No se conecta a Internet ni a un servidor.
