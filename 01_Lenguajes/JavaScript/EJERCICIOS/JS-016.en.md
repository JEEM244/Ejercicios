# JS-016 — Create list elements

- **Topic:** \`submit\`, \`preventDefault()\`, \`createElement()\`, and \`append()\`.
- **Level:** early intermediate.
- **Prerequisites:** JS-013 to JS-015.
- **Type:** guided practice.

## Goal

Create HTML elements from the text submitted through a form.

## Prompt

Complete a local task list. When the form is submitted, the program must read the field, create an \`li\` element, and add it to the list. The page must not reload.

## Requirements

- [ ] Select the form, field, and list.
- [ ] Listen for the form's \`submit\` event.
- [ ] Cancel the default submission with \`preventDefault()\`.
- [ ] Trim whitespace from the value with \`trim()\`.
- [ ] Do not add an item when the field is empty.
- [ ] Create an \`li\` element with \`document.createElement()\`.
- [ ] Set its text with \`textContent\` and add it with \`append()\`.
- [ ] Clear the field and return focus to the input.

## Starter files

Open [index.html](JS-016/index.html) and complete [app.js](JS-016/app.js).

## Tests

1. Add two different tasks: two list items should appear.
2. Submit an empty field: no empty task should appear.
3. Type text with spaces at the beginning and end: those spaces should be removed.
4. Make sure the document does not reload.
