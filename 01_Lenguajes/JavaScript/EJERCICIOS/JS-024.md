# JS-024 — Cargar datos locales con Fetch API

- **Tema:** fetch(), Response, response.ok y response.json().
- **Nivel:** intermedio.
- **Requisitos:** JS-013 a JS-018 y JSON.
- **Tipo:** práctica integradora.

## Objetivo

Solicitar un archivo JSON local, procesar la respuesta y mostrar los datos en una página.

## Enunciado

Completa una página que carga una lista de tareas desde `datos/tareas.json`. Debe mostrar un estado de carga, presentar los elementos recibidos y manejar los errores.

## Requisitos

- [ ] Selecciona el botón, la lista y el mensaje de estado.
- [ ] Registra un listener para cargar los datos.
- [ ] Crea una función asíncrona para consultar el archivo con `fetch()`.
- [ ] Comprueba `response.ok` antes de leer el cuerpo.
- [ ] Convierte la respuesta a JSON con `response.json()`.
- [ ] Crea un elemento `li` por cada tarea y presenta su texto con `textContent`.
- [ ] Muestra un mensaje cuando la lista esté vacía.
- [ ] Maneja errores con `try...catch`.
- [ ] Restablece el mensaje de estado al terminar.

## Archivos iniciales

Completa [app.js](JS-024/app.js), revisa [tareas.json](JS-024/datos/tareas.json) y abre [index.html](JS-024/index.html) desde un servidor HTTP local.

## Cómo ejecutarlo

No abras el HTML directamente desde el explorador de archivos. Usa Apache/XAMPP u otro servidor local. También puedes iniciar un servidor desde la carpeta del ejercicio con:

~~~bash
python -m http.server 8000
~~~

Después abre `http://localhost:8000` y navega al archivo del ejercicio.

## Pruebas

- Presiona el botón: deben aparecer las tres tareas del JSON.
- Cambia temporalmente el nombre del archivo en la ruta de fetch: debe aparecer el error HTTP.
- Reemplaza el arreglo del JSON por uno vacío: debe mostrarse el aviso de lista vacía.

## Nota

Este ejercicio lee un archivo local servido por tu propio entorno. No utiliza una API externa, no transmite datos personales y no guarda información.
