# JS-017 — Process a form

- **Topic:** the \`submit\` event, \`FormData\`, and reading controls.
- **Level:** early intermediate.
- **Prerequisites:** JS-016.
- **Type:** guided practice.

## Goal

Read data from several controls and display a summary on the page without sending it to a server.

## Prompt

Complete an activity registration form. It must collect a name, group, and shift. When submitted, it displays a summary of the entered data.

## Requirements

- [ ] Select the form and the summary area.
- [ ] Listen for \`submit\` on the form.
- [ ] Use \`preventDefault()\` to prevent navigation.
- [ ] Create a \`FormData\` object from the form.
- [ ] Read the data using each control's \`name\` attribute.
- [ ] Display the summary using \`textContent\`.
- [ ] Keep the HTML structure and do not use \`innerHTML\`.

## Starter files

Open [index.html](JS-017/index.html) and complete [app.js](JS-017/app.js).

## Tests

- Submit the sample data: Mara, 5L1, and Morning.
- Change one value and submit again.
- Make sure the summary displays the current data.
- Enter HTML tags as text and check that they appear as text, not as elements.

## Note

The exercise does not send data or store it in a database. The summary exists only on the open page.
