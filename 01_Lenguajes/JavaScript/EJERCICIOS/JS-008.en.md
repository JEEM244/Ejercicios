# JS-008 — Transform and filter data

- **Topic:** map(), filter(), find(), and reduce().
- **Level:** beginner-intermediate.
- **Requirements:** JS-007 and functions.
- **Type:** practical exercise.

## Objective

Choose the right method to transform a list, filter items, find a match, and calculate a total.

## Task

You have a list of grades. Create a list with extra points, another with passing grades, find the first grade below 60, and calculate the average.

## Requirements

- [ ] Keep the original grades array.
- [ ] Use map() to create a new array that adds 5 points to each grade.
- [ ] Use filter() to keep grades of 70 or higher.
- [ ] Use find() to search for the first grade below 60.
- [ ] Use reduce() to add the original grades.
- [ ] Calculate and display the average without changing the original array.

## Starter file

Complete [ejercicio.js](JS-008/ejercicio.js).

## Expected result

With the sample grades, the extra-points array should be [90, 67, 99, 75, 63], passing grades [85, 94, 70], the first grade below 60 should be 58, and the average 73.8.

## Check your work

Change one grade and verify that all four results update.
