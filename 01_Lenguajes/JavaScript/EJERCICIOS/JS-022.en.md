# JS-022 — Chain promises

- **Topic:** Promise, then(), catch(), and finally().
- **Level:** early intermediate.
- **Prerequisites:** functions, conditionals, and arrow functions.
- **Type:** guided practice.

## Goal

Create a simulated asynchronous operation and process its result with a promise chain.

## Prompt

Complete a \`checkStatus()\` function that simulates a request. It must return a promise that fulfills or rejects after a short delay.

## Requirements

- [ ] Create a \`checkStatus(successful)\` function.
- [ ] The function must return a \`Promise\` instance.
- [ ] Use \`setTimeout()\` to simulate a delay.
- [ ] If \`successful\` is true, call \`resolve()\` with a message.
- [ ] If it is false, call \`reject()\` with an Error object.
- [ ] Consume the promise with \`then()\`, \`catch()\`, and \`finally()\`.
- [ ] Run one successful test and one rejected test.

## Starter file

Complete [ejercicio.js](JS-022/ejercicio.js) and run it:

~~~bash
node ejercicio.js
~~~

## Tests

- The successful request should display the resolved message.
- The failed request should display the error message.
- The finally block should run in both cases.

## Note

The timer only simulates an asynchronous operation. It does not connect to the Internet or a server.
