# JS-014 — Event-driven counter

- **Topic:** `addEventListener()`, clicks, and state.
- **Level:** beginner-intermediate.
- **Prerequisites:** JS-013.
- **Type:** guided practice.

## Goal

Use different buttons to update a variable and display its value on the page.

## Prompt

Complete a counter with buttons to increase, decrease, and reset its value. The value must update without reloading the page.

## Requirements

- [ ] Select the value and the three buttons.
- [ ] Declare a variable to store the counter.
- [ ] Use `addEventListener()` to listen for clicks.
- [ ] Increase the counter by one with the appropriate button.
- [ ] Decrease the counter by one with the second button.
- [ ] Reset the counter to zero with the third button.
- [ ] Update the page after every operation.

## Starter files

Open [index.html](JS-014/index.html) and complete [app.js](JS-014/app.js).

## Tests

- Increase the value three times: it should display 3.
- Decrease it once: it should display 2.
- Reset it: it should display 0.
- Make sure the page does not reload.
