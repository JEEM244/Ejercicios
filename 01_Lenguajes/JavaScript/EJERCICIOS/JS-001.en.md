# JS-001 — Variables and template literals

- **Topic:** variables, const, let, and template literals.
- **Level:** beginner.
- **Requirements:** know how to use console.log().
- **Type:** practical exercise.

## Objective

Declare variables, tell const and let apart, and display values inside a text string.

## Task

Customize the welcome message for a small learning log. Change the name and the number of completed practices. Then display both values using template literals.

## Requirements

- [ ] Declare the name with const.
- [ ] Declare completed practices with let.
- [ ] Update the number of practices at least once.
- [ ] Display one message with the name and another with the total.
- [ ] Use backticks and ${} expressions to insert values.

## Starter file

Work in [ejercicio.js](JS-001/ejercicio.js).

## Expected result

With the sample values, the console should display a greeting for Alex and say that 3 practices have been completed.

## Check your work

Change the name and the number. Confirm that the output updates without changing the output statements.
