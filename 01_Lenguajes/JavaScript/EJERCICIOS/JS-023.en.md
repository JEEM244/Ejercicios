# JS-023 — Use async, await, and Promise.all

- **Topic:** async functions, await, try...catch, and Promise.all().
- **Level:** intermediate.
- **Prerequisites:** JS-022.
- **Type:** guided practice.

## Goal

Rewrite a promise-based request using async/await and run two independent tasks in parallel.

## Prompt

A dashboard needs to load the names of two sample groups. Complete two functions that simulate requests with different delays and a main function that waits for both operations.

## Requirements

- [ ] Create a `loadGroup(name, delay)` function that returns a promise.
- [ ] Use `setTimeout()` to simulate the duration.
- [ ] Create an `async` function named `startDashboard()`.
- [ ] Run both requests with `Promise.all()`.
- [ ] Use `await` to receive their results.
- [ ] Handle errors with `try...catch`.
- [ ] Use `finally` to display that the process finished.
- [ ] Do not run the requests sequentially when they do not depend on each other.

## Starter file

Complete [ejercicio.js](JS-023/ejercicio.js) and run it:

~~~bash
node ejercicio.js
~~~

## Tests

- Both requests should appear in the final result.
- Change each group's delay.
- Force one request to reject and check that the catch block receives the error.
