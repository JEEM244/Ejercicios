# JS-024 — Load local data with the Fetch API

- **Topic:** fetch(), Response, response.ok, and response.json().
- **Level:** intermediate.
- **Prerequisites:** JS-013 to JS-018 and JSON.
- **Type:** integrated practice.

## Goal

Request a local JSON file, process the response, and display the data on a page.

## Prompt

Complete a page that loads a task list from \`datos/tareas.json\`. It must display a loading status, render the received items, and handle errors.

## Requirements

- [ ] Select the button, list, and status message.
- [ ] Register a listener to load the data.
- [ ] Create an asynchronous function to request the file with \`fetch()\`.
- [ ] Check \`response.ok\` before reading the body.
- [ ] Convert the response to JSON with \`response.json()\`.
- [ ] Create an \`li\` for each task and display its text with \`textContent\`.
- [ ] Display a message when the list is empty.
- [ ] Handle errors with \`try...catch\`.
- [ ] Reset the status message when the process finishes.

## Starter files

Complete [app.js](JS-024/app.js), review [tasks.json](JS-024/datos/tareas.json), and open [index.html](JS-024/index.html) from a local HTTP server.

## How to run it

Do not open the HTML directly from the file explorer. Use Apache/XAMPP or another local server. You can also start a server from the exercise folder with:

~~~bash
python -m http.server 8000
~~~

Then open \`http://localhost:8000\` and navigate to the exercise file.

## Tests

- Press the button: the three tasks from the JSON file should appear.
- Temporarily change the filename in the fetch path: an HTTP error should appear.
- Replace the JSON array with an empty one: the empty-list notice should appear.

## Note

This exercise reads a local file served by your own environment. It does not use an external API, transmit personal data, or store information.
