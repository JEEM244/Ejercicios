# JS-017 — Procesar un formulario

- **Tema:** evento \`submit\`, \`FormData\` y lectura de controles.
- **Nivel:** intermedio inicial.
- **Requisitos:** JS-016.
- **Tipo:** práctica guiada.

## Objetivo

Leer los datos de varios controles y mostrar un resumen en la página sin enviarlos a un servidor.

## Enunciado

Completa un formulario de registro para una actividad. Debe capturar nombre, grupo y turno. Al enviarlo, muestra un resumen con los datos escritos.

## Requisitos

- [ ] Selecciona el formulario y el área de resumen.
- [ ] Escucha \`submit\` en el formulario.
- [ ] Usa \`preventDefault()\` para evitar la navegación.
- [ ] Crea un objeto \`FormData\` a partir del formulario.
- [ ] Lee los datos mediante los atributos \`name\` de los controles.
- [ ] Muestra el resumen usando \`textContent\`.
- [ ] Conserva la estructura del HTML y no uses \`innerHTML\`.

## Archivo inicial

Abre [index.html](JS-017/index.html) y completa [app.js](JS-017/app.js).

## Pruebas

- Envía los datos de prueba: Mara, 5L1 y Matutino.
- Cambia uno de los valores y vuelve a enviar.
- Comprueba que el resumen muestre los datos actuales.
- Escribe etiquetas HTML como texto y verifica que se muestren como texto, no como elementos.

## Nota

El ejercicio no envía datos ni los guarda en una base de datos. El resumen solo existe en la página abierta.
