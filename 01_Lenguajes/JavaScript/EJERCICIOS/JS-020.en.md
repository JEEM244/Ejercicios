# JS-020 — Default exports and modules

- **Topic:** default exports, imports, and separation of responsibilities.
- **Level:** early intermediate.
- **Prerequisites:** JS-019.
- **Type:** guided practice.

## Goal

Combine a default export and a named export in one module.

## Prompt

Build a small welcome card. The `mensajes.js` module must create the main message and export a helper function to normalize a name. The main file reads the field and displays the result.

## Requirements

- [ ] In `modulos/mensajes.js`, create a function that trims whitespace from a name.
- [ ] Export that function by name.
- [ ] Create a main function that receives the name and returns a welcome message.
- [ ] Export the main function as the default export.
- [ ] Import both functions from `app.js`.
- [ ] Read the name from the field.
- [ ] If the field is empty, display a notice.
- [ ] Display the result with `textContent`.

## Starter files

Open [index.html](JS-020/index.html) from a local HTTP server and complete:
- [app.js](JS-020/app.js)
- [mensajes.js](JS-020/modulos/mensajes.js)

## Tests

- Enter `  Mara  `: the message should use `Mara`, without surrounding spaces.
- Enter `Alex`: it should display a greeting for Alex.
- Leave the field empty: a notice should appear.
