# JS-020 — Exportación predeterminada y módulos

- **Tema:** export default, importaciones y separación de responsabilidades.
- **Nivel:** intermedio inicial.
- **Requisitos:** JS-019.
- **Tipo:** práctica guiada.

## Objetivo

Combinar una exportación predeterminada y una exportación con nombre en un módulo.

## Enunciado

Construye una pequeña tarjeta de bienvenida. El módulo \`mensajes.js\` debe crear el mensaje principal y exportar una función auxiliar para normalizar un nombre. El archivo principal lee el campo y presenta el resultado.

## Requisitos

- [ ] En \`modulos/mensajes.js\`, crea una función que quite espacios del nombre.
- [ ] Exporta esa función con nombre.
- [ ] Crea una función principal que reciba el nombre y devuelva el mensaje de bienvenida.
- [ ] Exporta la función principal como exportación predeterminada.
- [ ] Importa ambas funciones desde \`app.js\`.
- [ ] Lee el nombre desde el campo.
- [ ] Si el campo está vacío, muestra un aviso.
- [ ] Muestra el resultado con \`textContent\`.

## Archivos iniciales

Abre [index.html](JS-020/index.html) desde un servidor HTTP local y completa:
- [app.js](JS-020/app.js)
- [mensajes.js](JS-020/modulos/mensajes.js)

## Pruebas

- Escribe \`  Mara  \`: el mensaje debe usar \`Mara\`, sin espacios exteriores.
- Escribe \`Alex\`: debe mostrar un saludo para Alex.
- Deja el campo vacío: debe mostrarse un aviso.
