# JS-001 — Variables y plantillas de texto

- **Tema:** variables, const, let y template literals.
- **Nivel:** básico.
- **Requisitos:** conocer console.log().
- **Tipo:** ejercicio práctico.

## Objetivo

Declarar variables, distinguir entre const y let, y mostrar valores dentro de una cadena de texto.

## Enunciado

Personaliza el mensaje de bienvenida de un pequeño registro de aprendizaje. Cambia el nombre y la cantidad de prácticas completadas. Después, muestra ambos datos usando plantillas de texto.

## Requisitos

- [ ] Declara el nombre con const.
- [ ] Declara las prácticas completadas con let.
- [ ] Actualiza el número de prácticas al menos una vez.
- [ ] Muestra un mensaje con el nombre y otro con el total.
- [ ] Usa acentos graves y expresiones ${} para insertar valores.

## Archivo inicial

Trabaja en [ejercicio.js](JS-001/ejercicio.js).

## Resultado esperado

Con los valores de ejemplo, la consola debe mostrar un saludo para Alex y que ha completado 3 prácticas.

## Comprobación

Cambia el nombre y el número. Comprueba que el resultado se actualiza sin modificar las instrucciones de salida.
