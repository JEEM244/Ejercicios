# JS-021 — Convert and validate JSON data

- **Topic:** JSON.stringify(), JSON.parse(), and error handling.
- **Level:** early intermediate.
- **Prerequisites:** objects, arrays, and try...catch.
- **Type:** guided practice.

## Goal

Convert an object into JSON text and recover its data through parsing.

## Prompt

Complete a program that represents a student record. It must convert the object to JSON, display the generated text, and recover the values with \`JSON.parse()\`. Then it must handle malformed JSON text.

## Requirements

- [ ] Create an object with a name, group, and list of subjects.
- [ ] Convert the object to text with \`JSON.stringify()\`.
- [ ] Use two-space indentation to make the text readable.
- [ ] Recover the object with \`JSON.parse()\`.
- [ ] Display the recovered name and group.
- [ ] Attempt to parse invalid JSON text inside \`try...catch\`.
- [ ] Display a clear message when an error occurs.

## Starter file

Complete [ejercicio.js](JS-021/ejercicio.js) and run it:

~~~bash
node ejercicio.js
~~~

## Tests

- Check that the JSON text includes all three properties.
- Check that the recovered object keeps the data.
- Replace the invalid text with another malformed string and confirm that the program handles the error.
