# JS-013 — Select and update elements

- **Topic:** DOM, selectors, and text content.
- **Level:** beginner-intermediate.
- **Prerequisites:** basic HTML and JavaScript variables.
- **Type:** guided practice.

## Goal

Find HTML elements from JavaScript and change their content in a controlled way.

## Prompt

The starter page displays a title, a status paragraph, and a button. Complete the JavaScript file so that activating the button updates the title and message.

## Requirements

- [ ] Select the title by its ID.
- [ ] Select the message and the button.
- [ ] Register a listener for the \`click\` event.
- [ ] Change content with \`textContent\`.
- [ ] Change the button text after it is activated.
- [ ] Make sure the selectors match the HTML IDs.

## Starter files

Open [index.html](JS-013/index.html) in a browser and complete [app.js](JS-013/app.js).

## Expected result

After pressing the button, the page should display the title **"JavaScript is connected!"** and a message confirming that the DOM was updated. The button should change to **"Updated"**.

## Tests

1. Open the file before editing and observe the initial content.
2. Press the button and check all three changes.
3. Check the browser console for errors.
