# JS-006 — Funciones y valores de retorno

- **Tema:** declarar funciones, parámetros y return.
- **Nivel:** básico.
- **Requisitos:** JS-001 a JS-005.
- **Tipo:** ejercicio práctico.

## Objetivo

Crear funciones reutilizables que reciban valores y devuelvan resultados.

## Enunciado

Crea una función que calcule el área de un rectángulo y otra que genere un resumen con el nombre de la persona y el área calculada.

## Requisitos

- [ ] Declara calcularArea(ancho, alto).
- [ ] La función debe devolver ancho multiplicado por alto usando return.
- [ ] Declara crearResumen(nombre, ancho, alto).
- [ ] Usa calcularArea() dentro de crearResumen().
- [ ] Devuelve una plantilla de texto con el nombre y el área.
- [ ] Llama ambas funciones y muestra sus resultados.

## Archivo inicial

Completa [ejercicio.js](JS-006/ejercicio.js).

## Resultado esperado

Con los datos de ejemplo, el área debe ser 15 y el resumen debe mencionar a Alex y el resultado 15.

## Comprobación

Prueba la función con otro ancho y alto. Comprueba que el resultado cambie sin modificar las funciones.
