# JavaScript Exercises

A practice path from fundamentals to modules and asynchronous programming. Each exercise includes a prompt, starter files, and a separate solution.

## Requirements

- Review the [JavaScript guides](../README.en.md).
- Node.js for JS-001 to JS-012 and JS-021 to JS-023.
- A modern browser for JS-013 to JS-020 and JS-024.
- A local HTTP server for exercises that use modules and Fetch.

To run Node.js exercises, enter their folder and use:

~~~bash
node ejercicio.js
~~~

For JS-013 to JS-020 and JS-024, start a local server (for example, Apache/XAMPP) and open the \`index.html\` file through the local address. Do not open pages with modules or Fetch through \`file://\`.

## Workflow

1. Read the objective and requirements.
2. Open the starter files in the exercise folder.
3. Complete the TODO instructions or fix the intentional errors.
4. Run the code in its appropriate environment.
5. Try at least one different input or action.
6. Open the solution only after attempting the task.

Solutions are stored in [SOLUCIONES](../SOLUCIONES/). You do not need to install libraries or create another project.
