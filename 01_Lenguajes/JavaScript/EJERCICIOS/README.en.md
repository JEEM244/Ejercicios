# JavaScript Exercises

A practice path from fundamentals to data structures and debugging. Each exercise includes a prompt, a starter file, and a separate solution.

## Requirements

- Review [GUIA.en.md](../GUIA.en.md) and [GUIA_ESTRUCTURAS.en.md](../GUIA_ESTRUCTURAS.en.md).
- Node.js installed or a browser with developer tools.
- A text editor.

To run an exercise from the terminal, enter its folder and use:

~~~bash
node ejercicio.js
~~~

## Workflow

1. Read the objective and requirements.
2. Open the starter file in the exercise folder.
3. Complete the TODO instructions or fix the intentional errors.
4. Run the file and compare the output with the expected result.
5. Try at least one different input value.
6. Open the solution only after attempting the task.

Solutions are stored in [SOLUCIONES](../SOLUCIONES/). You do not need to install libraries or create another project.
