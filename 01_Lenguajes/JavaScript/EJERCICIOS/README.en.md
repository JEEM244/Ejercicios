# JavaScript Exercises

A practice path from fundamentals to data structures, debugging, and the DOM. Each exercise includes a prompt, a starter project, and a separate solution.

## Requirements

- Review the [JavaScript guides](../README.en.md).
- A modern browser for JS-013 to JS-018.
- Node.js is optional for running the first twelve exercises from the terminal.
- A text editor.

To run JS-001 to JS-012 from the terminal, enter the exercise folder and use:

~~~bash
node exercise.js
~~~

For JS-013 to JS-018, open the `index.html` file in each exercise folder in a browser.

## Workflow

1. Read the objective and requirements.
2. Open the starter file in the exercise folder.
3. Complete the TODO instructions or fix the intentional errors.
4. Run the code in its appropriate environment.
5. Try at least one different input or action.
6. Open the solution only after attempting the task.

Solutions are stored in [SOLUCIONES](../SOLUCIONES/). You do not need to install libraries or create another project.
