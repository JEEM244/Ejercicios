# JS-002 — Tipos de datos y conversiones

- **Tema:** string, number, boolean, typeof y Number().
- **Nivel:** básico.
- **Requisitos:** JS-001 y variables.
- **Tipo:** ejercicio práctico.

## Objetivo

Identificar el tipo de un dato y convertir texto numérico a number antes de realizar una operación.

## Enunciado

Tienes el precio y la cantidad de un producto almacenados como texto. Convierte esos valores a número, calcula el subtotal y muestra el tipo del dato original.

## Requisitos

- [ ] Conserva precioTexto y unidadesTexto como cadenas.
- [ ] Convierte ambos valores usando Number().
- [ ] Usa typeof para mostrar el tipo de precioTexto.
- [ ] Calcula el subtotal con los valores convertidos.
- [ ] Usa Number.isNaN() para revisar si la conversión del precio falló.

## Archivo inicial

Completa [ejercicio.js](JS-002/ejercicio.js).

## Resultado esperado

Con los datos de ejemplo: producto Cuaderno, precio 125, unidades 3 y subtotal 375. El tipo original del precio debe ser string y la conversión no debe producir NaN.

## Comprobación

Cambia precioTexto por "dato" y observa qué pasa. Después restáuralo a un valor numérico válido.
