# JS-005 — for and while loops

- **Topic:** repetition, counters, accumulators, and conditions.
- **Level:** beginner.
- **Requirements:** JS-001 to JS-004.
- **Type:** practical exercise.

## Objective

Repeat instructions with for and while, and use an accumulator to add values.

## Task

First, loop through numbers 1 to 5 with for and calculate their sum. Then use while to display a countdown from 3 to 1.

## Requirements

- [ ] Declare an accumulator starting at 0.
- [ ] Use for to loop from 1 to 5.
- [ ] Add the current number on each iteration.
- [ ] Display the final sum.
- [ ] Use while to display 3, 2, and 1.
- [ ] Update the while counter so the loop ends.

## Starter file

Complete [ejercicio.js](JS-005/ejercicio.js).

## Expected result

The final sum should be 15 and the countdown should display 3, 2, and 1. It must not run indefinitely.

## Check your work

Change the for loop limit to 10 and check the new sum. Then restore the original limit.
