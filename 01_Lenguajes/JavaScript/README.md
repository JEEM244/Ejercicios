# JavaScript

**Estado:** ruta inicial de fundamentos creada.  
**Nivel actual:** básico.  
**Enfoque:** sintaxis, datos, operadores, decisiones, ciclos y funciones.

JavaScript permite escribir la lógica de una aplicación y agregar interacción a páginas web. También puede ejecutarse fuera del navegador con entornos como Node.js.

## Material

- [Referencia rápida](REFERENCIA.md)
- [Ejercicios JS-001 a JS-006](EJERCICIOS/README.md)

## Temas incluidos

- Cómo ejecutar un archivo JavaScript en el navegador y con Node.js.
- Comentarios, instrucciones y salida con console.log().
- Variables con const y let.
- Tipos primitivos y conversiones.
- Operadores aritméticos, comparación y lógica.
- Condicionales if, else y switch.
- Ciclos for y while.
- Funciones, parámetros y return.

## Convenciones de esta unidad

- Los ejemplos iniciales no necesitan frameworks ni paquetes externos.
- Cada ejercicio se puede ejecutar con Node.js o adaptar a la consola del navegador.
- El archivo inicial contiene indicaciones TODO.
- Las soluciones están en una carpeta separada. Intenta resolver antes de consultarlas.
- Se usa const por defecto y let cuando el valor necesita cambiar. var se explica como sintaxis antigua, no como opción recomendada.

Continuar con arreglos, objetos, métodos de cadenas y arreglos, alcance y depuración. Después se estudiarán DOM, eventos, módulos y programación asíncrona.
