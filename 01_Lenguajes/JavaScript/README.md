# JavaScript

**Estado:** estructura inicial; guía y ejercicios pendientes.

JavaScript es un lenguaje de programación utilizado para crear lógica e interacción en páginas y aplicaciones. También se ejecuta fuera del navegador mediante entornos como Node.js.

## Temas previstos

- Variables y constantes.
- Tipos primitivos y conversiones.
- Operadores y expresiones.
- Condicionales y ciclos.
- Funciones y alcance.
- Arreglos y objetos.
- Métodos de arreglos y cadenas.
- DOM y eventos.
- Módulos.
- Promesas y async/await.
- Manejo de errores.
- APIs del navegador y del entorno de ejecución.

## Notas

Se distinguirá JavaScript del navegador de JavaScript ejecutado en Node.js. Los temas de frameworks se documentarán por separado.
