# JavaScript

**Estado:** cuatro rutas de estudio creadas.  
**Nivel actual:** básico a intermedio.  
**Enfoque:** sintaxis, datos, interacción web, módulos y asincronía.

JavaScript permite escribir la lógica de una aplicación y agregar interacción a páginas web. También puede ejecutarse fuera del navegador con entornos como Node.js.

## Temas cubiertos

- Variables, tipos, conversiones, operadores, condicionales, ciclos y funciones.
- Arreglos, métodos, cadenas, objetos y desestructuración.
- Alcance de variables, lectura de errores y depuración.
- DOM, selectores, atributos, clases, nodos y eventos.
- Formularios, FormData, validación y accesibilidad básica.
- Módulos con exportaciones e importaciones con nombre y predeterminadas.
- JSON: serialización, análisis y manejo de errores.
- Promesas, then(), catch(), finally(), async/await y Promise.all().
- Fetch API, respuestas HTTP, JSON remoto o local y manejo de errores.

## Organización

La ruta contiene cuatro bloques:

1. **Fundamentos:** JS-001 a JS-006.
2. **Estructuras y depuración:** JS-007 a JS-012.
3. **DOM y eventos:** JS-013 a JS-018.
4. **Módulos y asincronía:** JS-019 a JS-024.

Cada ejercicio incluye enunciado bilingüe, archivos iniciales y solución independiente. JS-001 a JS-012 y JS-021 a JS-023 se pueden ejecutar con Node.js. JS-013 a JS-020 y JS-024 requieren un navegador; los ejercicios con módulos o Fetch se deben abrir desde un servidor HTTP local. No se necesitan frameworks ni paquetes externos.

## Forma de trabajo

1. Lee la guía del bloque.
2. Abre el enunciado y los archivos iniciales.
3. Completa los TODO antes de abrir la solución.
4. Ejecuta cada práctica en el entorno indicado.
5. Cambia los datos de prueba y revisa los errores.
6. Compara tu resultado con la solución.

Se usa const por defecto y let cuando el valor necesita cambiar. var se explica como sintaxis antigua, no como opción recomendada.

## Siguiente etapa

Después de practicar estas bases, conviene revisar el funcionamiento en navegador real y continuar con TypeScript o con proyectos que integren DOM, módulos y APIs.
