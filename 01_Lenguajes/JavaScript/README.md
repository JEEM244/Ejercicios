# JavaScript

**Estado:** rutas de fundamentos, estructuras y DOM creadas.  
**Nivel actual:** básico-intermedio.  
**Enfoque:** sintaxis, datos, depuración e interacción con páginas web.

JavaScript permite escribir la lógica de una aplicación y agregar interacción a páginas web. También puede ejecutarse fuera del navegador con entornos como Node.js.

## Temas cubiertos

- Ejecución en navegador y Node.js.
- Variables, tipos, conversiones y operadores.
- Condicionales, ciclos y funciones.
- Arreglos, índices y recorridos.
- Métodos forEach(), map(), filter(), find() y reduce().
- Métodos de cadenas, objetos, propiedades y estructuras anidadas.
- Arreglos de objetos y desestructuración.
- Alcance global, de función y de bloque.
- Depuración, lectura de errores y puntos de interrupción.
- DOM: selectores, texto, clases, atributos y creación de elementos.
- Eventos click, input, change y submit.
- Formularios, FormData y validación del navegador.
- Accesibilidad básica y uso seguro de textContent.

## Organización

La ruta contiene tres bloques de estudio:

1. **Fundamentos:** JS-001 a JS-006.
2. **Estructuras y depuración:** JS-007 a JS-012.
3. **DOM y eventos:** JS-013 a JS-018.

Cada ejercicio incluye un enunciado en español e inglés, un proyecto inicial y una solución independiente. Los primeros doce ejercicios trabajan con JavaScript general y pueden ejecutarse con Node.js. Los ejercicios DOM deben abrirse en un navegador porque utilizan document y elementos HTML. No requieren frameworks ni paquetes externos.

## Forma de trabajo

1. Lee la guía del tema.
2. Abre el enunciado y el archivo inicial.
3. Completa los TODO o corrige los errores indicados.
4. Para JS-001 a JS-012, ejecuta el archivo JavaScript con Node.js o en la consola del navegador.
5. Para JS-013 a JS-018, abre el archivo index.html en un navegador.
6. Prueba datos y acciones diferentes.
7. Compara con la solución solo después de intentarlo.

Se usa const por defecto y let cuando el valor necesita cambiar. var se explica como sintaxis antigua, no como opción recomendada.
