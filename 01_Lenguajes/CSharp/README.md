# C#

**Estado:** estructura inicial; guía y ejercicios pendientes.

C# es un lenguaje moderno de la plataforma .NET. Se utiliza para desarrollar aplicaciones de escritorio, servicios, herramientas, videojuegos y otros sistemas.

## Temas previstos

- Estructura de un proyecto .NET.
- Variables, tipos y operadores.
- Condicionales y ciclos.
- Métodos y parámetros.
- Arreglos y colecciones.
- Clases, objetos e interfaces.
- Herencia y polimorfismo.
- Excepciones.
- LINQ.
- Genéricos.
- Archivos y serialización.
- Programación asíncrona con async/await.
- Pruebas y depuración.

## Notas

Se indicará la versión de .NET y C# cuando afecte al ejemplo. Se separarán las características del lenguaje de las APIs de .NET.
