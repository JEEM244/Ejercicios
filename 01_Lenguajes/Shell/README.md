# Shell

**Estado:** estructura inicial; guía y ejercicios pendientes.

Shell permite interactuar con el sistema operativo y automatizar tareas mediante comandos y scripts. Esta sección separa **Bash** y **PowerShell**, porque no comparten toda su sintaxis ni su modelo de objetos.

## Bash

- Navegación y archivos.
- Variables y expansión.
- Comillas y redirecciones.
- Tuberías y códigos de salida.
- Condicionales y ciclos.
- Funciones y scripts.
- Permisos y procesos.

## PowerShell

- Cmdlets y ayuda.
- Variables y tipos.
- Pipeline basado en objetos.
- Condicionales y ciclos.
- Funciones y parámetros.
- Archivos, procesos y servicios.
- Módulos y scripts.

## Notas

Los ejemplos identificarán la shell y el sistema operativo. Los comandos que modifican archivos o configuración explicarán sus efectos antes de ejecutarse.
