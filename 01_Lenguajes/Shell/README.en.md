# Shell

**Status:** initial structure; guide and exercises are pending.

Shells let users interact with an operating system and automate tasks through commands and scripts. This section separates **Bash** and **PowerShell** because they do not share all syntax or the same object model.

## Bash

- Navigation and files.
- Variables and expansion.
- Quoting and redirection.
- Pipelines and exit codes.
- Conditionals and loops.
- Functions and scripts.
- Permissions and processes.

## PowerShell

- Cmdlets and help.
- Variables and types.
- Object-based pipeline.
- Conditionals and loops.
- Functions and parameters.
- Files, processes, and services.
- Modules and scripts.

## Notes

Examples will identify the shell and operating system. Commands that modify files or configuration will explain their effects before execution.
