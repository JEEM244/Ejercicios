# Lua

**Estado:** estructura inicial; guía y ejercicios pendientes.

Lua es un lenguaje ligero y embebible. Se utiliza en configuración, automatización, videojuegos y como lenguaje de scripting dentro de otras aplicaciones.

## Temas previstos

- Valores y tipos.
- Variables y alcance.
- Operadores y control de flujo.
- Funciones.
- Tablas.
- Iteradores.
- Módulos.
- Metatables.
- Coroutines.
- Manejo de errores.
- Integración con aplicaciones.

## Notas

Se explicará la diferencia entre las características del lenguaje y las funciones que agrega un motor o aplicación que integra Lua.
