# PHP

**Estado:** estructura inicial; guía y ejercicios pendientes.

PHP es un lenguaje de propósito general muy utilizado para generar contenido web del lado del servidor. También permite crear scripts y herramientas de línea de comandos.

## Temas previstos

- Sintaxis y etiquetas PHP.
- Variables, tipos y operadores.
- Condicionales y ciclos.
- Funciones y arreglos.
- Manejo de formularios.
- GET y POST.
- Sesiones y cookies.
- Archivos y directorios.
- Programación orientada a objetos.
- PDO y conexión a bases de datos.
- Validación, escape y seguridad.
- Organización de aplicaciones.

## Notas

Los ejemplos de base de datos identificarán el motor utilizado. Se distinguirá el código PHP de las funciones que dependen de Apache, PHP-FPM u otro servidor.
