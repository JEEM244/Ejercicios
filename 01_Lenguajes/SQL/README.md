# SQL

**Estado:** estructura inicial; guía y ejercicios pendientes.

SQL es un lenguaje utilizado para consultar y manipular datos en bases de datos relacionales. Los ejemplos distinguirán las instrucciones comunes de las particularidades de cada motor.

## Temas previstos

- Bases de datos, tablas, filas y columnas.
- Tipos de datos.
- SELECT, WHERE y ORDER BY.
- INSERT, UPDATE y DELETE.
- Funciones de agregación y GROUP BY.
- JOIN y relaciones.
- Subconsultas y CTE.
- CREATE, ALTER y DROP.
- Claves y restricciones.
- Índices.
- Transacciones.
- Vistas y procedimientos.
- Seguridad y consultas parametrizadas.

## Motores de referencia

- SQL estándar: conceptos compartidos cuando sea posible.
- SQL Server: T-SQL y particularidades de Microsoft SQL Server.
- MySQL: sintaxis y funciones propias de MySQL.

Cada ejemplo debe señalar el motor y versión cuando la sintaxis no sea portable.
