- Aggregate functions and GROUP BY.
- JOIN and relationships.
- Subqueries and CTEs.
- CREATE, ALTER, and DROP.
- Keys and constraints.
- Indexes.
- Transactions.
- Views and procedures.
- Security and parameterized queries.

## Reference engines

- SQL standard: shared concepts whenever possible.
- SQL Server: T-SQL and Microsoft SQL Server behavior.
- MySQL: MySQL-specific syntax and functions.

Every example must state the engine and version when syntax is not portable.
