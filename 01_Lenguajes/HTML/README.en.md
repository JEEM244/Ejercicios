# HTML

**Status:** in development.  
**Current level:** beginner-intermediate.  
**Main sources:** MDN and WHATWG.

HTML (HyperText Markup Language) defines the structure and meaning of web page content. It is a markup language, not a programming language.

## Covered topics

- Document structure, elements, tags, and attributes.
- Text, lists, links, images, and semantics.
- Data tables and forms.
- Audio, video, captions, and transcripts.
- Accessibility and markup validation.
- Metadata and global attributes.
- Loading external CSS and JavaScript.
- Responsive images and embedded content.
- Native interactive elements and status controls.

## Next expansion

Specialized topics, browser compatibility, maintenance practices, and an integrated exercise combining the material remain to be developed.

## Approach

HTML defines structure and semantics; CSS controls presentation and JavaScript adds behavior. Examples separate files according to their responsibilities.
