# HTML

**Status:** beginner-to-intermediate learning path completed.  
**Level:** beginner-intermediate.  
**Main sources:** MDN and WHATWG.

HTML defines the structure and meaning of web page content. It is a markup language, not a programming language.

- [HTML guide](GUIA.en.md)
- [Quick reference](REFERENCIA.en.md)

## Covered topics

- Document structure, elements, tags, attributes, and semantics.
- Text, lists, links, images, tables, and forms.
- Audio, video, captions, and accessibility.
- Metadata and global attributes.
- Loading external CSS and JavaScript.
- Responsive images, embedded content, and iframes.
- Native interactive elements.
- Validation, keyboard navigation, and resource organization.

## Capstone project

[HTML-010 — Learning library](EJERCICIOS/HTML-010.en.md) combines the topics in a small multi-page website.

## Remaining scope

The initial learning path is complete through intermediate level. Specialized topics, advanced forms, web components, browser APIs, and detailed browser compatibility remain as future extensions.

## Approach

HTML defines structure and semantics; CSS controls presentation and JavaScript adds behavior. Examples separate files according to their responsibilities.
