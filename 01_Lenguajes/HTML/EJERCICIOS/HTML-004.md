# HTML-004 — Crear una tabla de datos accesible

- **Tema:** tablas HTML
- **Nivel:** básico
- **Tipo:** completar y organizar información

## Objetivo

Representar información tabular con encabezados identificables y una descripción clara.

## Enunciado

Crea una tabla que compare tres lenguajes de programación que te gustaría estudiar. Muestra el nombre, su uso principal y tu estado de aprendizaje.

## Requisitos

1. Utiliza table para crear la tabla.
2. Incluye caption para describir su propósito.
3. Coloca los encabezados de columna dentro de thead.
4. Coloca las filas de datos dentro de tbody.
5. Usa th con scope="col" para los encabezados de columna.
6. Usa th con scope="row" para identificar cada lenguaje.
7. Usa td para las celdas que contienen datos.
8. Agrega al menos tres filas de lenguajes.

## Restricciones

- No utilices la tabla para acomodar el diseño general de la página.
- No reemplaces los encabezados th por celdas td.
- Los datos deben relacionarse claramente con sus encabezados.

## Resultado esperado

Una tabla con nombre, uso y estado de aprendizaje de al menos tres lenguajes.

## Casos de revisión

| Revisión | Resultado esperado |
|---|---|
| Descripción | La tabla tiene caption. |
| Encabezados | Las columnas usan th con scope="col". |
| Filas | Cada lenguaje usa th con scope="row". |
| Datos | La información usa celdas td. |
| Estructura | Se utilizan thead y tbody. |
