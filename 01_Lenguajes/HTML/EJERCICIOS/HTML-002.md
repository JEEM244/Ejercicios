# HTML-002 — Perfil personal semántico

- **Tema:** texto, enlaces, listas y semántica
- **Nivel:** básico
- **Tipo:** construir una página desde cero
- **Requisitos:** haber completado HTML-001

## Objetivo

Combinar elementos HTML y organizar una página con etiquetas semánticas.

## Instrucciones

Crea un archivo `perfil.html` con:

1. Un `header` con un encabezado principal.
2. Un `nav` con dos enlaces internos: "Sobre mí" y "Mis intereses".
3. Un `main` que contenga dos elementos `section`.
4. La primera sección debe tener un párrafo de presentación.
5. La segunda sección debe contener una lista con al menos tres intereses.
6. Un `footer` con un texto de cierre.

Usa información ficticia si prefieres no incluir datos personales reales.

## Resultado esperado

La página debe mostrar una estructura clara, con navegación hacia las dos secciones y contenido organizado.

## Criterios de aceptación

- [ ] Utiliza `header`, `nav`, `main`, `section` y `footer`.
- [ ] Los enlaces apuntan a IDs existentes.
- [ ] Cada sección tiene un encabezado.
- [ ] La lista tiene al menos tres elementos.
- [ ] No se utilizan etiquetas únicamente para cambiar la apariencia.

## Pistas

Un enlace interno puede apuntar a un identificador, por ejemplo `href="#intereses"`. El destino debe tener `id="intereses"`.
