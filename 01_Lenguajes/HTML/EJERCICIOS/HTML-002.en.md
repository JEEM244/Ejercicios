# HTML-002 — Semantic personal profile

- **Topic:** text, links, lists, and semantics
- **Level:** beginner
- **Type:** build a page from scratch
- **Requirements:** complete HTML-001 first

## Objective

Combine HTML elements and organize a page using semantic tags.

## Instructions

Create a perfil.html file with:

1. A header containing a main heading.
2. A nav with two in-page links: "About me" and "My interests".
3. A main element containing two section elements.
4. The first section must contain an introduction paragraph.
5. The second section must contain a list with at least three interests.
6. A footer containing a closing note.

Use fictional information if you prefer not to include real personal details.

## Expected result

The page should show a clear structure, with navigation to both sections and organized content.

## Acceptance criteria

- [ ] Uses header, nav, main, section, and footer.
- [ ] The links point to existing IDs.
- [ ] Each section has a heading.
- [ ] The list contains at least three items.
- [ ] Elements are not chosen only for their appearance.

## Hints

An in-page link can point to an identifier, for example href="#interests". The target must have id="interests".
