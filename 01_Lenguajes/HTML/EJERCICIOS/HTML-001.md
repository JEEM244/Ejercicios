# HTML-001 — Crear un documento básico

- **Tema:** estructura del documento
- **Nivel:** básico
- **Tipo:** crear desde cero
- **Requisitos:** editor de texto y navegador

## Objetivo

Crear una página HTML mínima y reconocer las partes principales del documento.

## Instrucciones

Crea un archivo `index.html` que incluya:

1. La declaración `<!doctype html>`.
2. El elemento `html` con idioma español.
3. Los metadatos UTF-8 y viewport.
4. Un título para la pestaña.
5. Un encabezado principal con el texto "Mi primera página".
6. Un párrafo que explique qué estás aprendiendo.
7. Una lista sin orden con tres tecnologías.

## Resultado esperado

Al abrir el archivo en el navegador deben aparecer el encabezado, el párrafo y la lista. El título debe verse en la pestaña.

## Criterios de aceptación

- [ ] El archivo se llama `index.html`.
- [ ] Contiene `html`, `head` y `body`.
- [ ] Declara el idioma español y UTF-8.
- [ ] Incluye un encabezado principal.
- [ ] La lista contiene tres elementos `li`.
- [ ] Los elementos están correctamente anidados.

## Pistas

- La lista sin orden utiliza `ul`.
- Cada elemento utiliza `li`.
- Los metadatos van dentro de `head`.
