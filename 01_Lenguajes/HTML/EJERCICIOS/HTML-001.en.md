# HTML-001 — Create a basic document

- **Topic:** document structure
- **Level:** beginner
- **Type:** create from scratch
- **Requirements:** text editor and browser

## Objective

Create a minimal HTML page and identify the main parts of the document.

## Instructions

Create an index.html file that includes:

1. The doctype declaration.
2. The html element with Spanish as its language.
3. UTF-8 and viewport metadata.
4. A browser tab title.
5. A main heading with the text "My first page".
6. A paragraph explaining what you are learning.
7. An unordered list with three technologies.

## Expected result

When the file is opened in a browser, the heading, paragraph, and list should appear. The title should appear in the browser tab.

## Acceptance criteria

- [ ] The file is named index.html.
- [ ] It contains html, head, and body.
- [ ] It declares Spanish and UTF-8.
- [ ] It includes a main heading.
- [ ] The list contains three li items.
- [ ] Elements are properly nested.

## Hints

- An unordered list uses ul.
- Each list item uses li.
- Metadata belongs inside head.
