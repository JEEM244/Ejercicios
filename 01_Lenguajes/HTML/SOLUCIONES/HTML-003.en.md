# Solution: HTML-003 — Semantic page

**Status:** reviewed for structure; no automated validator was run.

## Idea

Choose each element based on its purpose. Navigation uses fragment links, for example #concepts. The target must have the matching id value.

## File

[HTML-003.html](HTML-003.html)

## Important decisions

- header contains the site introduction.
- nav groups navigation links.
- main marks the main content.
- section separates concepts from resources.
- article contains an explanation that can stand on its own.
- footer presents a closing note.
