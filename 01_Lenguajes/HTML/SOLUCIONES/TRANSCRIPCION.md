# Transcripción de ejemplo

Este texto es una transcripción de muestra para acompañar los subtítulos del ejercicio HTML-006.

## Texto

Hola. En esta práctica estamos aprendiendo a organizar contenido multimedia con HTML.

El elemento audio permite reproducir sonido dentro de una página. El elemento video permite mostrar una grabación. Ambos pueden incluir controles para que la persona decida cuándo reproducir, pausar o ajustar el contenido.

Para que el video sea más accesible, podemos agregar una pista de subtítulos. También es útil proporcionar una transcripción que se pueda leer sin reproducir el archivo.

Fin de la transcripción.
