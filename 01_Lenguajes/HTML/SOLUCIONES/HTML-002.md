## Decisiones importantes

- header contiene el título y la navegación.
- nav agrupa los enlaces internos.
- main delimita el contenido principal.
- section separa la presentación y los intereses.
- footer contiene el cierre.
- Cada enlace interno debe coincidir con el id de su destino.
