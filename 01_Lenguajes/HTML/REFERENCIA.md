# Referencia rápida de HTML

## Estructura mínima

```html
<!doctype html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Título</title>
</head>
<body>
    <!-- Contenido -->
</body>
</html>
```

## Elementos frecuentes

| Elemento | Función |
|---|---|
| `h1`–`h6` | Encabezados |
| `p` | Párrafo |
| `a` | Enlace |
| `img` | Imagen |
| `ul`, `ol`, `li` | Listas |
| `strong` | Importancia |
| `em` | Énfasis |
| `br` | Salto de línea |
| `hr` | Separación temática |
| `div` | Contenedor genérico de bloque |
| `span` | Contenedor genérico en línea |

## Elementos semánticos

`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.

## Atributos comunes

| Atributo | Uso |
|---|---|
| `id` | Identificador único dentro del documento |
| `class` | Agrupa elementos para estilos o scripts |
| `href` | Destino de un enlace |
| `src` | Ubicación de un recurso |
| `alt` | Alternativa textual de una imagen |
| `title` | Información adicional |
| `lang` | Idioma del contenido |
| `type` | Tipo de control o recurso, según el elemento |
