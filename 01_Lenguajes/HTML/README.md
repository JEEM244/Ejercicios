# HTML

**Estado:** en desarrollo.  
**Nivel actual:** básico-intermedio.  
**Fuentes principales:** MDN y WHATWG.

HTML (HyperText Markup Language) define la estructura y el significado del contenido de una página web. Es un lenguaje de marcado, no un lenguaje de programación.

## Contenidos cubiertos

- Estructura, elementos, etiquetas y atributos.
- Texto, listas, enlaces, imágenes y semántica.
- Tablas de datos y formularios.
- Audio, video, subtítulos y transcripciones.
- Accesibilidad y validación del marcado.
- Metadatos y atributos globales.
- Carga de CSS y JavaScript externos.
- Imágenes adaptables y contenido incrustado.
- Elementos interactivos nativos y controles de estado.

## Siguiente ampliación

Quedan por desarrollar temas especializados, compatibilidad entre navegadores, buenas prácticas de mantenimiento y una práctica integradora que combine los contenidos.

## Enfoque

HTML define estructura y semántica; CSS controla la presentación y JavaScript añade comportamiento. Los ejemplos separan los archivos según su responsabilidad.
