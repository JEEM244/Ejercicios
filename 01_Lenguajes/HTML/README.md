# HTML

**Estado:** ruta inicial básico-intermedio completada.  
**Nivel:** básico-intermedio.  
**Fuentes principales:** MDN y WHATWG.

HTML define la estructura y el significado del contenido de una página web. Es un lenguaje de marcado, no un lenguaje de programación.

## Temas cubiertos

- Estructura, elementos, etiquetas, atributos y semántica.
- Texto, listas, enlaces, imágenes, tablas y formularios.
- Audio, video, subtítulos y accesibilidad.
- Metadatos y atributos globales.
- Carga de CSS y JavaScript externos.
- Imágenes adaptables, contenido incrustado e iframes.
- Elementos interactivos nativos.
- Validación, navegación por teclado y organización de recursos.
