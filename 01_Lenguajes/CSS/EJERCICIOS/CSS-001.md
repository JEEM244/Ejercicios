# CSS-001 — Conectar una hoja de estilos

- **Tema:** Conectar una hoja de estilos
- **Nivel:** Básico
- **Requisitos:** HTML básico
- **Tipo:** ejercicio práctico

## Objetivo

Conecta un archivo CSS externo al HTML y aplica reglas a elementos, clases e identificadores. Comprueba la ruta del archivo y evita los estilos en línea.

## Enunciado

Completa la hoja CSS para dar formato al título, al párrafo destacado y a la nota. Usa un selector de elemento, uno de clase y uno de ID. El HTML ya contiene los elementos y sus atributos.

## Requisitos

- [ ] El HTML enlaza css/estilos.css correctamente.
- [ ] El título recibe un color y tamaño propios.
- [ ] La clase .destacado modifica el párrafo marcado.
- [ ] El ID #nota tiene una regla independiente.
- [ ] No se utilizan atributos style en HTML.

## Archivos iniciales

Trabaja con [index.html](CSS-001/index.html) y [css/estilos.css](CSS-001/css/estilos.css).

## Entrega

Conserva los dos archivos dentro de la carpeta del ejercicio. Verifica que la hoja externa esté conectada y que el resultado siga siendo entendible al desactivar los estilos.
