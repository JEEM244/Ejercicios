# CSS-005 — Readable colors and typography

- **Topic:** Readable colors and typography
- **Level:** Beginner
- **Prerequisites:** basic HTML
- **Type:** practical exercise

## Objective

Build an information card with a consistent color combination, typographic hierarchy, and spacing.

## Prompt

Complete the card styles. Define text and background colors, font family, size, weight, and line height. Keep links recognizable and keyboard focus visible.

## Requirements

- [ ] Main text and background are clearly distinguishable.
- [ ] There is hierarchy between the heading, description, and link.
- [ ] Line height supports readability.
- [ ] The link retains a visual cue and visible focus.
- [ ] Information is not communicated through color alone.

## Starter files

Work with [index.html](CSS-005/index.html) and [css/estilos.css](CSS-005/css/estilos.css).

## Submission

Keep both files inside the exercise folder. Check that the external stylesheet is linked and that the content remains understandable when styles are disabled.
