# CSS-004 — Box model and dimensions

- **Topic:** Box model and dimensions
- **Level:** Beginner-intermediate
- **Prerequisites:** basic HTML
- **Type:** practical exercise

## Objective

Use width, max-width, padding, border, margin, and box-sizing to control a card's size.

## Prompt

Complete the rules so the card has a maximum width, inner spacing, border, and outer margin. Apply border-box globally. Explain why the final width becomes more predictable.

## Requirements

- [ ] Content, padding, border, and margin are distinguished.
- [ ] box-sizing: border-box is used.
- [ ] The card has max-width and can shrink in a narrow viewport.
- [ ] The illustration does not overflow its container.

## Starter files

Work with [index.html](CSS-004/index.html) and [css/estilos.css](CSS-004/css/estilos.css).

## Submission

Keep both files inside the exercise folder. Check that the external stylesheet is linked and that the content remains understandable when styles are disabled.
