# CSS-010 — Custom properties and themes

- **Topic:** Custom properties and themes
- **Level:** Intermediate
- **Prerequisites:** CSS-001 through CSS-005
- **Type:** practical exercise

## Objective

Organize repeated colors and spacing values into reusable custom properties.

## Prompt

Declare variables for the primary color, text, background, and spacing. Use them in the cards and button. Add an alternative card that overrides one variable without duplicating all the rules.

## Acceptance criteria

- [ ] Variables are declared in :root.
- [ ] Repeated values are consumed with var().
- [ ] The alternative card overrides one variable locally.
- [ ] All theme selectors are not duplicated just to change the variant.

## Starter files

- [index.html](CSS-010/index.html)
- [css/estilos.css](CSS-010/css/estilos.css)

## Submission

Keep the files separate and test the layout at different viewport widths. Also review keyboard navigation where relevant.
