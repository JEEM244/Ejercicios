# CSS-002 — Selectors and states

- **Topic:** Selectors and states
- **Level:** Beginner
- **Prerequisites:** basic HTML
- **Type:** practical exercise

## Objective

Practice class selectors, descendant selectors, direct children, pseudo-classes, and focus states.

## Prompt

Style the navigation and resource list using combinators. Links must show a state on hover and another when focused by keyboard. Do not remove the focus outline.

## Requirements

- [ ] The descendant selector is distinguished from the direct-child selector.
- [ ] Links change on :hover.
- [ ] Keyboard focus is visible with :focus-visible.
- [ ] Styles are applied without overly long selectors.

## Starter files

Work with [index.html](CSS-002/index.html) and [css/estilos.css](CSS-002/css/estilos.css).

## Submission

Keep both files inside the exercise folder. Check that the external stylesheet is linked and that the content remains understandable when styles are disabled.
