# CSS-012 — Capstone project: learning website

- **Level:** Intermediate
- **Prerequisites:** CSS-001 through CSS-011
- **Type:** multi-page capstone project
- **Deliverable:** three HTML pages and one shared CSS stylesheet

## Objective

Build a small learning website with a consistent visual identity and a layout that adapts to different viewport sizes.

## Prompt

Create a website called CodeVault with these pages:

1. **Home:** introduction, library summary, topic cards, and a call to action.
2. **Topics:** organize web development, programming, data, and networking areas. Include links to each section.
3. **Contact:** a form with name, email, topic, and message. Use visible labels and accessible controls.

All three pages must share the same external stylesheet.

## HTML requirements

- Declare the language and basic metadata.
- Use semantic elements: header, nav, main, section, article, and footer.
- Keep one main heading per page.
- Include navigation between all three pages.
- Associate each form label with its field.
- Mark the current page in navigation with aria-current.
- Include a skip link to the main content.

## CSS requirements

- Declare colors, spacing, radii, and maximum width with custom properties.
- Use Flexbox for the header, navigation, and call to action.
- Use Grid for cards and the main layout.
- Create at least two breakpoints based on content needs.
- Use clamp() for fluid sizing.
- Define hover and focus-visible states.
- Keep keyboard focus visible.
- Respect prefers-reduced-motion.
- Prevent horizontal overflow on narrow screens.
- Maintain readable contrast and text sizes.

## Acceptance criteria

- [ ] All three pages open and share the stylesheet.
- [ ] Navigation links connect the pages.
- [ ] Internal links on Topics jump to the correct section.
- [ ] Cards adapt to one, two, or three columns as space allows.
- [ ] The header and call to action can wrap their items.
- [ ] The form uses appropriate labels and field types.
- [ ] Navigation and form controls can be reached by keyboard.
- [ ] Focus is visually distinguishable.
- [ ] Narrow viewports do not cause horizontal scrolling.
- [ ] Motion is reduced when requested by the operating system.

## Manual tests

1. Open index.html and navigate through all three pages.
2. Test approximate viewport widths of 320 px, 768 px, and 1280 px.
3. Use Tab and Shift+Tab to review focus order.
4. Increase browser zoom and check that content remains available.
5. Temporarily disable CSS and verify that content order remains understandable.
6. Review the browser console and styles panel.

## Form scope

The form is a visual demonstration. Without a backend or form service, it does not send or store information. Do not enter real personal data while testing.

## Reflection

- Which parts of the site use Flexbox and which use Grid?
- Which breakpoint was necessary, and why?
- Which custom property made the design easier to change?
- What issues did you find when navigating with only a keyboard?
