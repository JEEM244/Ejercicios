# CSS-012 — Capstone project: CodeVault resource portal

- **Level:** intermediate
- **Type:** practical project
- **Prerequisites:** CSS-001 through CSS-011 and basic HTML

## Objective

Build a programming resource page that combines several layout methods and works on narrow and wide screens.

## Prompt

Create the home page for a learning portal with an introduction, study-area catalog, learning path, sample progress indicator, and frequently asked questions.

It does not require JavaScript or a server. Everything must work with HTML, CSS, and local assets.

## HTML requirements

1. Set language, charset, viewport, description, and title.
2. Link an external stylesheet and local icon.
3. Add a skip link to the main content.
4. Use header, nav, main, section, article, and footer where appropriate.
5. Add navigation links to the page sections.
6. Use one main heading and an ordered heading hierarchy.
7. Include a local image with alternative text.
8. Present FAQs with details and summary.
9. Use progress with a label for sample progress.
10. Keep a logical reading order and descriptive links.

## CSS requirements

1. Declare custom properties for colors, spacing, and widths in :root.
2. Apply box-sizing: border-box globally.
3. Use Flexbox for navigation and status indicators.
4. Use Grid for the hero, catalog, and learning-path region.
5. Include a badge positioned relative to its card.
6. Use pseudo-classes such as :hover and :focus-visible.
7. Use clamp() for fluid text sizing.
8. Add media queries based on available space.
9. Include short transitions and prefers-reduced-motion.
10. Prevent horizontal overflow and avoid unnecessary rigid widths.

## Restrictions

- Do not use frameworks, CSS libraries, or JavaScript.
- Do not load images, fonts, or styles from external services.
- Do not use tables for page layout.
- Do not remove focus indicators.
- Do not use motion as the only way to communicate information.
- Keep HTML and CSS separate.

## Acceptance criteria

- [ ] The page uses semantic elements and an ordered heading hierarchy.
- [ ] Navigation links point to existing sections.
- [ ] Main colors and spacing are controlled from :root.
- [ ] Flexbox distributes navigation and status indicators.
- [ ] Grid organizes the hero, catalog, and learning path.
- [ ] The badge is positioned relative to its card.
- [ ] Content reorganizes without horizontal scrolling.
- [ ] There is a skip link, alternative text, visible focus, and reduced-motion support.
- [ ] CSS and images load from local paths.

Complete [index.html](CSS-012/index.html), [css/estilos.css](CSS-012/css/estilos.css), and review the local SVG files.

## Submission

Test the page at three or more widths: narrow, medium, and wide. Navigate with Tab and Shift + Tab.

Check HTML with [Nu HTML Checker](https://validator.w3.org/nu/) and CSS with the [W3C CSS Validation Service](https://jigsaw.w3.org/css-validator/).
