# CSS-004 — Modelo de caja y dimensiones

- **Tema:** Modelo de caja y dimensiones
- **Nivel:** Básico-intermedio
- **Requisitos:** HTML básico
- **Tipo:** ejercicio práctico

## Objetivo

Aplica width, max-width, padding, border, margin y box-sizing para controlar el tamaño de una tarjeta.

## Enunciado

Completa las reglas para que la tarjeta tenga un ancho máximo, espacio interno, borde y margen exterior. Aplica border-box de forma global. Explica por qué el ancho final se vuelve más predecible.

## Requisitos

- [ ] Se distinguen content, padding, border y margin.
- [ ] Se utiliza box-sizing: border-box.
- [ ] La tarjeta tiene max-width y puede reducirse en una ventana estrecha.
- [ ] El bloque ilustrativo no se desborda de su contenedor.

## Archivos iniciales

Trabaja con [index.html](CSS-004/index.html) y [css/estilos.css](CSS-004/css/estilos.css).

## Entrega

Conserva los dos archivos dentro de la carpeta del ejercicio. Verifica que la hoja externa esté conectada y que el resultado siga siendo entendible al desactivar los estilos.
