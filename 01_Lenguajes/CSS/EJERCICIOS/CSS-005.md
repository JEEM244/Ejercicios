# CSS-005 — Colores y tipografía legibles

- **Tema:** Colores y tipografía legibles
- **Nivel:** Básico
- **Requisitos:** HTML básico
- **Tipo:** ejercicio práctico

## Objetivo

Construye una tarjeta de información con una combinación coherente de color, jerarquía tipográfica y espaciado.

## Enunciado

Completa los estilos de la tarjeta. Define colores de texto y fondo, familia tipográfica, tamaño, grosor y altura de línea. Conserva los enlaces reconocibles y un foco de teclado visible.

## Requisitos

- [ ] El texto principal y el fondo se distinguen claramente.
- [ ] Hay jerarquía entre título, descripción y enlace.
- [ ] La altura de línea facilita la lectura.
- [ ] El enlace conserva una señal visual y un foco visible.
- [ ] No se comunica información únicamente con color.

## Archivos iniciales

Trabaja con [index.html](CSS-005/index.html) y [css/estilos.css](CSS-005/css/estilos.css).

## Entrega

Conserva los dos archivos dentro de la carpeta del ejercicio. Verifica que la hoja externa esté conectada y que el resultado siga siendo entendible al desactivar los estilos.
