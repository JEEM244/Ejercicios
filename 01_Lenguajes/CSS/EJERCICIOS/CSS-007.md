# CSS-007 — Distribución con Flexbox

- **Tema:** Distribución con Flexbox
- **Nivel:** Intermedio
- **Requisitos:** CSS-001 a CSS-005
- **Tipo:** ejercicio práctico

## Objetivo

Distribuye tarjetas en un eje y permite que salten de línea cuando no hay espacio.

## Enunciado

Convierte el contenedor de tarjetas en un diseño Flexbox. Usa gap, flex-wrap y flex para que las tarjetas crezcan y se reduzcan, manteniendo un ancho base razonable. Alinea su contenido y evita anchos fijos.

## Criterios de aceptación

- [ ] El contenedor utiliza display: flex.
- [ ] Las tarjetas pueden pasar a una nueva línea.
- [ ] La propiedad flex establece una base flexible para cada tarjeta.
- [ ] Se utiliza gap para separar los elementos.
- [ ] El contenido sigue en orden lógico.

## Archivos iniciales

- [index.html](CSS-007/index.html)
- [css/estilos.css](CSS-007/css/estilos.css)

## Entrega

Conserva los archivos separados y prueba la distribución con diferentes anchos de ventana. Revisa también la navegación por teclado cuando corresponda.
