# CSS-007 — Distribución con Flexbox

- **Tema:** Distribución con Flexbox
- **Nivel:** Intermedio
- **Requisitos:** CSS-001 a CSS-005
- **Tipo:** ejercicio práctico

## Objetivo

Arrange cards along one axis and let them wrap when space is limited.

## Enunciado

Turn the card container into a Flexbox layout. Use gap, flex-wrap, and flex so cards can grow and shrink while keeping a reasonable base size. Align their content and avoid fixed widths.

## Criterios de aceptación

- [ ] The container uses display: flex.
- [ ] Cards can wrap onto another line.
- [ ] The flex property gives each card a flexible base size.
- [ ] The gap property separates the items.
- [ ] Content remains in a logical order.
