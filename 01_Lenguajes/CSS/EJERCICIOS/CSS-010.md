# CSS-010 — Variables personalizadas y temas

- **Tema:** Variables personalizadas y temas
- **Nivel:** Intermedio
- **Requisitos:** CSS-001 a CSS-005
- **Tipo:** ejercicio práctico

## Objetivo

Organiza colores y espacios repetidos en variables reutilizables.

## Enunciado

Declara variables para color principal, texto, fondo y espacio. Úsalas en la tarjeta y el botón. Agrega una variante de tarjeta que sobrescriba una variable sin duplicar todas las reglas.

## Criterios de aceptación

- [ ] Las variables se declaran en :root.
- [ ] Los valores repetidos se consumen con var().
- [ ] La tarjeta alternativa sobrescribe una variable localmente.
- [ ] No se duplican todos los selectores para cambiar el tema.
