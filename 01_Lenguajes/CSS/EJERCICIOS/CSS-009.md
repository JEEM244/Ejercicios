# CSS-009 — Diseño adaptable y media queries

- **Tema:** Diseño adaptable y media queries
- **Nivel:** Intermedio
- **Requisitos:** CSS-001 a CSS-005
- **Tipo:** ejercicio práctico

## Objetivo

Adapta un catálogo a distintos anchos de pantalla sin depender de tamaños concretos de dispositivos.

## Enunciado

Haz que el catálogo muestre una columna por defecto y más columnas cuando exista espacio suficiente. Ajusta el tamaño del título con clamp y evita el desbordamiento horizontal. Prueba varios anchos, no solo los dos breakpoints de ejemplo.

## Criterios de aceptación

- [ ] El diseño empieza con una columna.
- [ ] Se utilizan media queries con breakpoints relacionados con el contenido.
- [ ] El título utiliza clamp() para un tamaño fluido.
- [ ] La página no obliga a desplazarse horizontalmente con el ancho de prueba.
- [ ] Se explica la diferencia entre media query y container query.

Conserva los archivos separados y prueba la distribución con diferentes anchos de ventana. Revisa también la navegación por teclado cuando corresponda.
