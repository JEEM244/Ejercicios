# CSS-009 — Diseño adaptable y media queries

- **Tema:** Diseño adaptable y media queries
- **Nivel:** Intermedio
- **Requisitos:** CSS-001 a CSS-005
- **Tipo:** ejercicio práctico

## Objetivo

Adapt a resource catalog to different viewport widths without targeting specific device sizes.

## Enunciado

Make the catalog display one column by default and add columns when enough space is available. Adjust the heading size with clamp and prevent horizontal overflow. Test several widths, not only the two sample breakpoints.

## Criterios de aceptación

- [ ] The layout starts with one column.
- [ ] Media queries use breakpoints based on content needs.
- [ ] The heading uses clamp for fluid sizing.
- [ ] The tested viewport widths do not force horizontal scrolling.
- [ ] The difference between media queries and container queries is explained.
