# CSS-008 — Estructura bidimensional con Grid

- **Tema:** Estructura bidimensional con Grid
- **Nivel:** Intermedio
- **Requisitos:** CSS-001 a CSS-005
- **Tipo:** ejercicio práctico

## Objetivo

Build a page layout with header, navigation, main content, and footer areas.

## Enunciado

Use CSS Grid to create a layout with a full-width header, side navigation, main content, and footer. Use named areas to express the structure. On narrow screens, place the regions in a single column.

## Criterios de aceptación

- [ ] The container uses display: grid.
- [ ] Columns and areas are defined with grid-template-areas.
- [ ] Each section is assigned to its matching grid area.
- [ ] Main content can shrink without overflowing.
- [ ] The layout changes to one column in a narrow viewport.
