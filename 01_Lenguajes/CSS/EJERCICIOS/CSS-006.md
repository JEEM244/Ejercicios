# CSS-006 — Flujo normal y posicionamiento

- **Tema:** Flujo normal y posicionamiento
- **Nivel:** Intermedio
- **Requisitos:** CSS-001 a CSS-005
- **Tipo:** ejercicio práctico

## Objetivo

Distinguish normal flow from positioned layout, and use position to overlay a badge without rearranging the entire page.

## Enunciado

The card includes a badge that should appear in its top-right corner. Position the badge relative to the card. Keep the remaining content in normal flow and add a container with limited vertical scrolling.

## Criterios de aceptación

- [ ] The card establishes the containing block for the badge.
- [ ] The badge is overlaid without removing the paragraphs from normal flow.
- [ ] The list has a maximum height and scrolls when needed.
- [ ] The difference between relative and absolute is explained.
