# CSS-006 — Flujo normal y posicionamiento

- **Tema:** Flujo normal y posicionamiento
- **Nivel:** Intermedio
- **Requisitos:** CSS-001 a CSS-005
- **Tipo:** ejercicio práctico

## Objetivo

Distingue el flujo normal y utiliza position para superponer una etiqueta sin alterar toda la estructura de la página.

## Enunciado

La tarjeta contiene una etiqueta que debe ubicarse en su esquina superior derecha. Haz que la etiqueta se posicione respecto a la tarjeta. Mantén el resto del contenido en el flujo normal y agrega un contenedor con desplazamiento vertical limitado.

## Criterios de aceptación

- [ ] La tarjeta establece el bloque contenedor para la etiqueta.
- [ ] La etiqueta se superpone sin sacar los párrafos del flujo normal.
- [ ] La lista tiene una altura máxima y desplazamiento vertical cuando hace falta.
- [ ] Se explica la diferencia básica entre relative y absolute.
