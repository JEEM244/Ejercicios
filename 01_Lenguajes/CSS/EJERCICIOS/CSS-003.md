# CSS-003 — Cascada, especificidad y herencia

- **Tema:** Cascada, especificidad y herencia
- **Nivel:** Básico-intermedio
- **Requisitos:** HTML básico
- **Tipo:** ejercicio práctico

## Objetivo

Identifica qué regla gana cuando varios selectores modifican la misma propiedad. Comprueba cómo se heredan algunas propiedades.

## Enunciado

Antes de modificar el archivo, predice el color y tamaño final de cada texto. Después completa las reglas para conseguir el resultado esperado sin utilizar !important. Escribe una explicación breve de la especificidad.

## Requisitos

- [ ] Se explica por qué una regla de clase puede ganar a una regla de elemento.
- [ ] Se identifica el efecto del ID en la especificidad.
- [ ] Se reconoce una propiedad heredada desde body.
- [ ] No se utiliza !important.

## Archivos iniciales

Trabaja con [index.html](CSS-003/index.html) y [css/estilos.css](CSS-003/css/estilos.css).

## Entrega

Conserva los dos archivos dentro de la carpeta del ejercicio. Verifica que la hoja externa esté conectada y que el resultado siga siendo entendible al desactivar los estilos.
