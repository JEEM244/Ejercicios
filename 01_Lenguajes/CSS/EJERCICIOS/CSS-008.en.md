# CSS-008 — Two-dimensional layout with Grid

- **Topic:** Two-dimensional layout with Grid
- **Level:** Intermedio
- **Prerequisites:** CSS-001 through CSS-005
- **Type:** practical exercise

## Objective

Construye una distribución de página con áreas de encabezado, navegación, contenido y pie.

## Prompt

Utiliza CSS Grid para crear una estructura con encabezado a lo ancho, menú lateral, contenido principal y pie. Usa nombres de área para expresar la estructura. En pantallas estrechas, coloca las zonas en una sola columna.

## Acceptance criteria

- [ ] El contenedor utiliza display: grid.
- [ ] Se definen columnas y áreas con grid-template-areas.
- [ ] Cada sección se asigna a su área correspondiente.
- [ ] El contenido principal puede reducirse sin desbordar.
- [ ] La estructura cambia a una columna en una ventana estrecha.
