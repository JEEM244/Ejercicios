# CSS-003 — Cascade, specificity, and inheritance

- **Topic:** Cascade, specificity, and inheritance
- **Level:** Beginner-intermediate
- **Prerequisites:** basic HTML
- **Type:** practical exercise

## Objective

Identify which rule wins when multiple selectors change the same property. Check how some properties are inherited.

## Prompt

Before editing the file, predict the final color and size of each text. Then complete the rules to achieve the expected result without using !important. Write a short explanation of specificity.

## Requirements

- [ ] The exercise explains why a class rule can beat a type rule.
- [ ] The effect of an ID on specificity is identified.
- [ ] An inherited property from body is recognized.
- [ ] !important is not used.

## Starter files

Work with [index.html](CSS-003/index.html) and [css/estilos.css](CSS-003/css/estilos.css).

## Submission

Keep both files inside the exercise folder. Check that the external stylesheet is linked and that the content remains understandable when styles are disabled.
