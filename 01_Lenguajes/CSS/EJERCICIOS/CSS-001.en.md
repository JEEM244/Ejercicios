# CSS-001 — Link an external stylesheet

- **Topic:** Link an external stylesheet
- **Level:** Beginner
- **Prerequisites:** basic HTML
- **Type:** practical exercise

## Objective

Connect an external CSS file to the HTML and apply rules to elements, classes, and IDs. Check the file path and avoid inline styles.

## Prompt

Complete the CSS file to style the heading, highlighted paragraph, and note. Use a type selector, a class selector, and an ID selector. The HTML already contains the elements and their attributes.

## Requirements

- [ ] The HTML correctly links css/estilos.css.
- [ ] The heading receives its own color and size.
- [ ] The .destacado class changes the marked paragraph.
- [ ] The #nota ID has its own rule.
- [ ] No style attributes are used in HTML.

## Starter files

Work with [index.html](CSS-001/index.html) and [css/estilos.css](CSS-001/css/estilos.css).

## Submission

Keep both files inside the exercise folder. Check that the external stylesheet is linked and that the content remains understandable when styles are disabled.
