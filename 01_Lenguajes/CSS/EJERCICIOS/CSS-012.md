# CSS-012 — Proyecto integrador: portal de recursos CodeVault

- **Nivel:** intermedio
- **Tipo:** proyecto práctico
- **Requisitos:** CSS-001 a CSS-011 y HTML básico

## Objetivo

Construir una página de recursos de programación que combine varios modelos de distribución y funcione en pantallas estrechas y amplias.

## Enunciado

Crea la portada de un portal de aprendizaje con una introducción, catálogo de áreas de estudio, ruta de aprendizaje, indicador de avance y preguntas frecuentes.

No requiere JavaScript ni servidor. Todo debe funcionar con HTML, CSS y recursos locales.

## Requisitos de HTML

1. Define idioma, charset, viewport, descripción y título.
2. Enlaza una hoja CSS externa y el icono local.
3. Agrega un enlace para saltar al contenido principal.
4. Usa header, nav, main, section, article y footer según corresponda.
5. Añade enlaces de navegación a las secciones.
6. Usa un título principal único y encabezados ordenados.
7. Incluye una imagen local con texto alternativo.
8. Presenta preguntas frecuentes con details y summary.
9. Usa progress con label para mostrar un avance de ejemplo.
10. Conserva un orden de lectura lógico y enlaces descriptivos.

## Requisitos de CSS

1. Declara variables personalizadas para colores, espacios y anchos en :root.
2. Aplica box-sizing: border-box de forma global.
3. Utiliza Flexbox para la navegación y los indicadores.
4. Utiliza Grid para el hero, el catálogo y la zona de ruta.
5. Incluye una etiqueta posicionada respecto a su tarjeta.
6. Usa pseudoclases como :hover y :focus-visible.
7. Utiliza clamp() para un tamaño de texto fluido.
8. Añade media queries según el espacio disponible.
9. Incluye transiciones breves y prefers-reduced-motion.
10. Evita el desbordamiento horizontal y los anchos rígidos innecesarios.

## Restricciones

- No uses frameworks, librerías CSS ni JavaScript.
- No cargues imágenes, fuentes ni estilos desde servicios externos.
- No uses tablas para distribuir la página.
- No elimines los indicadores de foco.
- No uses movimiento como única forma de comunicar información.
- Mantén HTML y CSS separados.

## Criterios de aceptación

- [ ] La página utiliza elementos semánticos y encabezados ordenados.
- [ ] La navegación lleva a secciones existentes.
- [ ] Los colores y espacios principales se controlan desde :root.
- [ ] Flexbox distribuye navegación e indicadores.
- [ ] Grid organiza hero, catálogo y ruta.
- [ ] La etiqueta se posiciona respecto a su tarjeta.
- [ ] El contenido se reorganiza sin desplazamiento horizontal.
- [ ] Hay skip link, texto alternativo, foco visible y movimiento reducido.
- [ ] CSS e imágenes se cargan desde rutas locales.

## Archivos iniciales

Completa [index.html](CSS-012/index.html), [css/estilos.css](CSS-012/css/estilos.css) y revisa los SVG locales.

## Entrega

Prueba la página con al menos tres anchos: estrecho, intermedio y amplio. Navega con Tab y Shift + Tab.

Revisa el HTML con [Nu HTML Checker](https://validator.w3.org/nu/) y el CSS con [W3C CSS Validation Service](https://jigsaw.w3.org/css-validator/).
