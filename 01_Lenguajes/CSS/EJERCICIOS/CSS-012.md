# CSS-012 — Proyecto integrador: sitio de aprendizaje

- **Nivel:** Intermedio
- **Prerrequisitos:** CSS-001 a CSS-011
- **Tipo:** proyecto integrador de varias páginas
- **Entrega:** tres páginas HTML y una hoja CSS compartida

## Objetivo

Construir un pequeño sitio de aprendizaje con una identidad visual coherente y una distribución que se adapte a diferentes tamaños de pantalla.

## Enunciado

Desarrolla un sitio llamado CodeVault con estas páginas:

1. **Inicio:** presentación, resumen de la biblioteca, tarjetas de áreas y llamada a la acción.
2. **Temas:** organiza las áreas de desarrollo web, programación, datos y redes. Incluye enlaces internos a cada sección.
3. **Contacto:** formulario con nombre, correo, tema y mensaje. Debe tener etiquetas visibles y controles accesibles.

Las tres páginas deben compartir la misma hoja de estilos externa.

## Requisitos de HTML

- Declara el idioma y los metadatos básicos.
- Utiliza elementos semánticos: header, nav, main, section, article y footer.
- Mantén un único encabezado principal por página.
- Incluye navegación entre las tres páginas.
- Usa etiquetas label asociadas a cada campo del formulario.
- Indica la página actual en la navegación con aria-current.
- Incluye un enlace para saltar al contenido principal.

## Requisitos de CSS

- Declara colores, espacios, radios y ancho máximo mediante custom properties.
- Utiliza Flexbox para la cabecera, navegación y llamada a la acción.
- Utiliza Grid para las tarjetas y la estructura principal.
- Crea al menos dos breakpoints según las necesidades del contenido.
- Utiliza clamp() para tamaños fluidos.
- Define estados hover y focus-visible.
- Mantén visible el foco de teclado.
- Respeta prefers-reduced-motion.
- Evita desbordamiento horizontal en pantallas estrechas.
- Mantén contraste y tamaños de texto legibles.

## Criterios de aceptación

- [ ] Las tres páginas abren y comparten estilos.
- [ ] La navegación permite cambiar entre páginas.
- [ ] Los enlaces internos de Temas llevan a su sección.
- [ ] Las tarjetas se acomodan en una, dos o tres columnas según el espacio.
- [ ] La cabecera y la llamada a la acción permiten envolver elementos.
- [ ] El formulario tiene etiquetas y tipos de campo adecuados.
- [ ] Se puede recorrer la navegación y el formulario con teclado.
- [ ] El foco se distingue visualmente.
- [ ] No aparece desplazamiento horizontal en anchos pequeños.
- [ ] El diseño reduce movimiento cuando el sistema lo solicita.

## Pruebas manuales

1. Abre index.html y recorre las tres páginas.
2. Prueba anchos aproximados de 320 px, 768 px y 1280 px.
3. Usa Tab y Shift+Tab para revisar el orden de foco.
4. Aumenta el zoom del navegador y revisa que el contenido siga disponible.
5. Desactiva CSS temporalmente y comprueba que el contenido conserva un orden comprensible.
6. Revisa la consola y el panel de estilos del navegador.

## Alcance del formulario

El formulario es una demostración visual. Sin backend o un servicio de formularios no envía ni almacena información. No agregues datos personales reales durante las pruebas.
