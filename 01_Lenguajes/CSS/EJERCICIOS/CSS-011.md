# CSS-011 — Transiciones, transformaciones y animaciones

- **Tema:** Transiciones, transformaciones y animaciones
- **Nivel:** Intermedio
- **Requisitos:** CSS-001 a CSS-005
- **Tipo:** ejercicio práctico

## Objetivo

Añade movimiento breve y controlado, y respeta las preferencias de movimiento reducido.

## Enunciado

Agrega una transición al botón para sus estados hover y focus-visible. Incluye una animación breve de entrada en la tarjeta con @keyframes. Desactiva esos efectos cuando el usuario indique que prefiere movimiento reducido.

## Criterios de aceptación

- [ ] El botón utiliza transition en propiedades concretas.
- [ ] La transformación es moderada y no oculta contenido.
- [ ] La animación se define con @keyframes.
- [ ] prefers-reduced-motion elimina los efectos de movimiento.
- [ ] El foco del teclado sigue siendo visible.
