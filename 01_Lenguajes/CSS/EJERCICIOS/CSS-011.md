# CSS-011 — Transiciones, transformaciones y animaciones

- **Tema:** Transiciones, transformaciones y animaciones
- **Nivel:** Intermedio
- **Requisitos:** CSS-001 a CSS-005
- **Tipo:** ejercicio práctico

## Objetivo

Add brief, controlled motion and respect reduced-motion preferences.

## Enunciado

Add a transition to the button's hover and focus-visible states. Include a short entrance animation on the card with @keyframes. Disable these effects when the user requests reduced motion.

## Criterios de aceptación

- [ ] The button uses transitions on specific properties.
- [ ] The transformation is subtle and does not hide content.
- [ ] The animation is defined with @keyframes.
- [ ] prefers-reduced-motion removes the motion effects.
- [ ] Keyboard focus remains visible.
