# CSS

**Status:** beginner-to-intermediate learning path with a capstone project.  
**Current level:** beginner-intermediate.  
**Focus:** external stylesheets, selectors, cascade, box model, layout, responsive design, and motion.

CSS describes the presentation of HTML documents. This directory separates explanations, references, exercises, and solutions.

## Covered topics

- Syntax, selectors, combinators, pseudo-classes, and pseudo-elements.
- Cascade, specificity, inheritance, and box model.
- Units, colors, typography, and overflow.
- Normal flow, positioning, and stacking.
- Flexbox and CSS Grid.
- Media queries, responsive design, and container queries.
- Custom properties.
- Transitions, transforms, animations, and reduced motion.
- Visual accessibility, keyboard focus, and debugging.

## Status

CSS-001 through CSS-011 cover fundamentals and layout. CSS-012 combines those skills in three HTML pages with one shared stylesheet, navigation, responsive cards, and a demonstration form.

Repository paths have been checked. Local browser testing and automated validation are still pending.
