# Solution — CSS-006

La tarjeta usa position: relative para convertirse en referencia de la etiqueta absoluta. La etiqueta sale del flujo normal, pero el resto permanece en su orden. overflow-y: auto permite desplazar la lista cuando el contenido supera la altura permitida.
