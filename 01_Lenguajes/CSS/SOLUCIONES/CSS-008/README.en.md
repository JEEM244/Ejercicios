# Solution — CSS-008

Grid organiza la estructura en dos dimensiones. El diseño empieza con una columna y cambia a menú lateral más contenido cuando hay suficiente espacio. grid-template-areas permite asignar zonas mediante nombres; minmax(0, 1fr) evita que la columna flexible fuerce un ancho excesivo.
