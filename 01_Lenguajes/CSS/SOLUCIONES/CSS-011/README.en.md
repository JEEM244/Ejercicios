# Solution — CSS-011

transition suaviza los cambios de propiedades entre estados. transform cambia la presentación visual sin alterar el flujo. @keyframes define la animación de entrada. La consulta prefers-reduced-motion elimina la animación y las transiciones si el sistema del usuario solicita menos movimiento.
