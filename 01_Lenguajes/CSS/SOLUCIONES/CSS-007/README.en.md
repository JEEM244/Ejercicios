# Solution — CSS-007

Flexbox distribuye los elementos en un eje principal. flex-wrap permite varias líneas, gap define los espacios y flex: 1 1 14rem permite que cada tarjeta crezca o se reduzca desde una base de 14rem. Un Flexbox interno alinea el contenido de cada tarjeta en columna.
