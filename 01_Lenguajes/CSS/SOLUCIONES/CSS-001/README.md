# Solución — CSS-001

El archivo HTML conecta una hoja externa con link. El selector h1 apunta al tipo de elemento, .destacado utiliza la clase y #nota utiliza el ID. Las clases son la opción habitual para estilos reutilizables; el ID se reserva para identificar un elemento único.
