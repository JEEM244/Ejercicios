# Solución — CSS-003

El selector p tiene especificidad de tipo; .mensaje y .especial tienen especificidad de clase. #principal .especial contiene un ID y una clase, así que gana entre estas reglas. El párrafo dentro de .panel hereda la fuente y el color de body porque no tiene una regla más directa para esas propiedades.
