# Solución — CSS-004

El modelo de caja separa contenido, padding, borde y margen. Con border-box, el width declarado incluye padding y borde; por eso el ancho máximo es más sencillo de controlar. La ilustración usa una altura mínima y un fondo para no depender de un recurso externo.
