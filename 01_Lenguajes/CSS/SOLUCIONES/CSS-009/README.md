# Solución — CSS-009

El diseño comienza con una columna y agrega más cuando el espacio lo permite. clamp limita el tamaño del título entre un mínimo y un máximo. Las media queries observan el viewport; las container queries, en cambio, permiten responder al tamaño de un contenedor específico.
