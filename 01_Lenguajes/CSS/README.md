# CSS

**Estado:** primera unidad de fundamentos disponible.  
**Nivel actual:** básico.  
**Enfoque:** estilos externos, selectores, cascada, modelo de caja, color y tipografía.

CSS (Cascading Style Sheets) describe la presentación de documentos HTML. Esta carpeta separa las explicaciones, la consulta rápida, los ejercicios y las soluciones.

## Temas disponibles

- Sintaxis de reglas y conexión de hojas externas.
- Selectores de elemento, clase, ID, atributo y combinadores.
- Pseudoclases y pseudoelementos.
- Cascada, especificidad y herencia.
- Modelo de caja, box-sizing y unidades.
- Colores, tipografía y display inicial.
- Depuración y buenas prácticas.

## Ejercicios

La primera tanda contiene cinco ejercicios, desde conectar una hoja externa hasta construir una tarjeta con tipografía y colores legibles.

## Siguiente ampliación

- Flujo normal, posicionamiento y desbordamiento.
- Flexbox y alineación.
- CSS Grid.
- Diseño adaptable y media queries.
- Variables personalizadas.
- Transiciones, transformaciones y animaciones.
- Formularios, estados y accesibilidad visual.
