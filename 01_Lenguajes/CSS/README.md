# CSS

**Estado:** estructura inicial; guía y ejercicios pendientes.

CSS (Cascading Style Sheets) describe la presentación de documentos, principalmente HTML. Controla colores, tipografía, distribución, adaptación a pantallas y otros aspectos visuales.

## Temas previstos

- Formas de aplicar CSS.
- Selectores, combinadores y pseudoclases.
- Cascada, herencia y especificidad.
- Modelo de caja y unidades.
- Colores, tipografía y fondos.
- Display y posicionamiento.
- Flexbox y Grid.
- Diseño responsive y media queries.
- Transiciones, transformaciones y animaciones.
- Variables y organización de estilos.
