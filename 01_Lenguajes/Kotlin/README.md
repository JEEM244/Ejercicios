# Kotlin

**Estado:** estructura inicial; guía y ejercicios pendientes.

Kotlin es un lenguaje moderno interoperable con Java. Se utiliza en desarrollo Android y también en aplicaciones de servidor, escritorio y multiplataforma.

## Temas previstos

- Sintaxis básica y ejecución.
- Variables y tipos.
- Null safety.
- Condicionales y ciclos.
- Funciones y lambdas.
- Clases, objetos y data classes.
- Interfaces y herencia.
- Colecciones.
- Genéricos.
- Extensiones.
- Corrutinas.
- Interoperabilidad con Java.

## Notas

Se distinguirá Kotlin del lenguaje Java y de las APIs específicas de Android. Las corrutinas se estudiarán después de las funciones y el manejo básico de errores.
