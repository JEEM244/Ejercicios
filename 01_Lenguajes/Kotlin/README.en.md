# Kotlin

**Status:** initial structure; guide and exercises are pending.

Kotlin is a modern language interoperable with Java. It is used for Android development as well as server, desktop, and multiplatform applications.

## Planned topics

- Basic syntax and execution.
- Variables and types.
- Null safety.
- Conditionals and loops.
- Functions and lambdas.
- Classes, objects, and data classes.
- Interfaces and inheritance.
- Collections.
- Generics.
- Extensions.
- Coroutines.
- Java interoperability.

## Notes

Kotlin will be distinguished from Java and Android-specific APIs. Coroutines will be studied after functions and basic error handling.
