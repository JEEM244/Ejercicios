# TypeScript

**Estado:** estructura inicial; guía y ejercicios pendientes.

TypeScript amplía JavaScript con un sistema de tipos estático que permite describir y comprobar la forma de los datos durante el desarrollo. El código suele transformarse para ejecutarse en un entorno JavaScript.

## Temas previstos

- Relación entre TypeScript y JavaScript.
- Configuración de un proyecto.
- Inferencia y anotaciones de tipos.
- Tipos primitivos, arreglos y objetos.
- Interfaces y alias.
- Uniones e intersecciones.
- Narrowing y guards.
- Funciones y sobrecargas.
- Genéricos.
- Clases y modificadores.
- Módulos y configuración del compilador.

## Notas

Se explicará qué comprobaciones realiza TypeScript y qué validaciones deben hacerse durante la ejecución.
